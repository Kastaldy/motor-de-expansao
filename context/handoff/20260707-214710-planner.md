### Passo 3 — Funções públicas

**3.1 `carregar_ultra(parquet_path: Path | str) -> pd.DataFrame`**
- Lê o parquet. Valida `COLS_OBRIGATORIAS` presentes → senão `raise ValueError(f"colunas obrigatórias ausentes: {faltando}")`.
- Coerce numérico: `metragem`, `alunos_total`, `ticket_medio_aluno` → float via `pd.to_numeric(errors="coerce")`.
- Deriva `alunos_por_m2` se ausente: `alunos_total / metragem` (guard `np.errstate` divide/invalid, como em `batch_viabilidade.carregar_base_calibracao`). Se já existir, coerce.
- Filtra linhas válidas: `metragem>0 & alunos_total>0 & alunos_por_m2 finito>0 & ticket_medio_aluno finito>0`.
- **RESET índice** com `.reset_index(drop=True)` (CRÍTICO — o LOO usa índice posicional para `drop`).
- Retorna DataFrame com colunas mínimas `['unidade','metragem','alunos_total','ticket_medio_aluno','alunos_por_m2']` (preservar `unidade` como label de negócio; NÃO propagar lat/lng nem outras colunas do parquet original → evita PII/geo).
- Se vazio após limpeza → `raise ValueError("base Ultra vazia após limpeza")`.

**3.2 `calcular_loo_base(df_ultra: pd.DataFrame, idx: int) -> pd.DataFrame`**
- `return df_ultra.drop(index=idx).reset_index(drop=True)` — base de calibração LOO SEM a unidade `idx`.
- A base LOO precisa ter `alunos_por_m2` (e `metragem` p/ janela) — já garantido por 3.1.
- Guard: `if idx not in df_ultra.index: raise KeyError`.

**3.3 `rodar_unidade_loo(row: pd.Series, df_ultra: pd.DataFrame, idx: int, *, aluguel_ref: float = SIM_ALUGUEL_MES, margem_alvo: float = MARGEM_ALVO_DEFAULT) -> dict`**
- `base_loo = calcular_loo_base(df_ultra, idx)`.
- `m2 = float(row["metragem"])`, `alunos_real = float(row["alunos_total"])`, `ticket = float(row["ticket_medio_aluno"])`.
- 1 chamada ao motor (coordless):
```python

    lat=LAT_COORDLESS, lng=LNG_COORDLESS, m2=m2,

    margem_alvo=margem_alvo,

```
- Extrai predições (`faixa_alunos_p10/p50/p90`, `n_comparaveis`, `alunos_breakeven`, `alunos_para_margem_alvo`, `aluguel_teto_calculado`, `viabilidade.flag_viavel`).
- Deriva métricas (ver Passo 4) e retorna o dict com as colunas de `COLUNAS_SAIDA`.

**3.4 `rodar_backtest(df_ultra: pd.DataFrame, *, aluguel_ref=SIM_ALUGUEL_MES, margem_alvo=MARGEM_ALVO_DEFAULT) -> pd.DataFrame`**
> Assinatura RECEBE `df_ultra` já carregado (permite teste sem IO). Fornecer overload por caminho via `run()`.
- Loop `for idx, row in df_ultra.iterrows(): linhas.append(rodar_unidade_loo(row, df_ultra, idx, ...))`.

- **Guard anti-PII de saída**: assert que nenhuma coluna de `PII_COLUNAS_PROIBIDAS` (case-insensitive) está em `df.columns` antes de retornar; senão `raise ValueError`. (`unidade` NÃO está na lista proibida — é label de negócio permitido.)
- Retorna `df` (ordem natural = ordem do parquet; sem sort obrigatório).

**3.5 `calcular_metricas_agregadas(df: pd.DataFrame) -> dict`**
- Arrays: `real = df["alunos_real"].to_numpy(float)`, `pred = df["faixa_alunos_p50_predito"].to_numpy(float)`.
- `mae = float(np.mean(np.abs(pred - real)))` (sobre finitos; guard vazio → nan).
- `mape = _mape(real, pred)` (fração; comparar com `MAE_MATERIAL_PCT` no relatório).
- `vies = float(np.mean(pred - real))` (viés assinado: +=motor superestima alunos; −=subestima).
- `rmse = _rmse(real, pred)`, `r2 = _r2(real, pred)`.
- `cobertura_intervalo = float(df["faixa_contem_real"].mean())` (% de unidades com real ∈ [p10,p90]).
- `pct_viavel = float(df["flag_viavel"].mean())`.
- `n = int(len(df))`, `n_extrapolacao = int(df["flag_extrapolacao"].sum())`.
- Retorna dict com todas essas chaves + `versao_contrato = VERSAO_CONTRATO`.

**3.6 `materializar(df_backtest: pd.DataFrame, metricas: dict, analysis_dir: Path | str) -> Path`**
