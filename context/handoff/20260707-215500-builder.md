## Resultado do backtest (dado real, N=54)
- **Veredito: erro DENTRO do limiar material** (MAPE p50 = 26.8% ≤ 40% → não dispara recalibração;
  DEC-008: este bloco só MEDE).
- **MAE = 636.02 alunos** (p50 vs real).
- **Viés = −118.53 alunos** (mean(pred−real); o motor tende a SUBESTIMAR levemente os alunos reais).
- RMSE = 857.36 · R² = 0.158.
- **Cobertura do intervalo [p10,p90] = 70.4%** (38/54 unidades têm o real dentro da faixa predita).
- % viável (cenário aluguel-ref R$20k, ticket real por unidade) = 16.7%.
- N extrapolação (janela estreita ±20% < 3 comparáveis) = 2.
- **Top-3 piores erros** (todos SUBESTIMAM — unidades de alta densidade real):
  PRAIA GRANDE (real 6.251 / p50 3.864 / erro −2.387 / −38.2%);
  BOTAFOGO (real 3.984 / p50 1.788 / erro −2.196);
  SUZANO (real 4.016 / p50 2.018 / erro −1.998).
- Leitura: a curva de densidade acerta a faixa em ~70% dos casos; os erros materiais concentram-se
  em unidades outlier de alunos/m² muito acima da mediana dos comparáveis (LOO as isola por janela
  de m²), que a p50 naturalmente comprime — resultado honesto, esperado, não bug.
