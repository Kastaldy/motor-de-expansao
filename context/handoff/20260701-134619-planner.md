**1.5 Helper de bootstrap do IC do rho**
```python
def _bootstrap_spearman_ci(
    x: np.ndarray, y: np.ndarray, *, n_boot: int = N_BOOTSTRAP, seed: int = SEED
) -> tuple[float, float]:
    """IC95 (2.5%, 97.5%) do Spearman rho por bootstrap dos pares (x, y), seed fixo.

    RNG: np.random.default_rng(seed) (determinístico). Reamostra com reposição os índices,
    recalcula spearmanr; descarta reamostras sem variância (unique(xb)<2 ou unique(yb)<2).
    Retorna (nan, nan) se x/y têm < N_MIN_PAR pontos ou nenhuma reamostra válida.
    """
```
- Espelhar `_ic_bootstrap_r2` de `backtest_tp05.py` (linhas 311–338): `rng = default_rng(seed)`,
  `idx = rng.integers(0, m, size=m)`, teto de tentativas `10 * n_boot`, `np.percentile(arr, [2.5, 97.5])`.
- **Determinismo**: mesmo `(x, y, seed)` → mesmo IC. Testado explicitamente (item 6c).

**1.6 Função principal pública**
```python
def analisar_correlacao_territorio_retencao(df: pd.DataFrame) -> list[ResultadoPar]:
    """Para cada par de PARES: dropa linhas com QUALQUER das duas variáveis NaN, calcula
    Spearman rho + p + IC95 bootstrap sobre o N efetivo, e classifica ic_cruza_zero. READ-ONLY."""
```
- Para cada `(feature, target)` em `PARES`:
  1. `x = pd.to_numeric(df[feature], errors="coerce")`; `y = pd.to_numeric(df[target], errors="coerce")`.
  2. `mask = x.notna() & y.notna()`; `n = int(mask.sum())`.
  3. Se `n < N_MIN_PAR` ou `x[mask].nunique() < 2` ou `y[mask].nunique() < 2` →
     `ResultadoPar(..., n=n, rho=nan, ci_low=nan, ci_high=nan, p_value=nan, ic_cruza_zero=True)`.
  4. Senão: `rho, p = spearmanr(x[mask], y[mask])`;
     `ci_low, ci_high = _bootstrap_spearman_ci(x[mask].to_numpy(float), y[mask].to_numpy(float))`.
  5. `ic_cruza_zero = not (np.isfinite(ci_low) and np.isfinite(ci_high)) or (ci_low <= 0.0 <= ci_high)`.
  6. `eixo = "absoluto" if target == ALVO_ABSOLUTO else "ranking"`.
- Retorna a lista na ordem determinística de `PARES`. NÃO ordena por rho (evita editorializar).

### 3. Regra GO/NO-GO (mecânica, sem editorializar)
- **GO** se e somente se **existe pelo menos 1 par** cujo **IC95 NÃO cruza zero**
  (`ci_low > 0` OU `ci_high < 0`) **E** `abs(rho) >= LIMIAR_RHO_GO` (**0.30**).
- **NO-GO** em qualquer outro caso (todos os ICs cruzam zero, ou os que não cruzam têm |rho|<0.30).
- **Justificativa documentada do limiar 0.30**: em N=44–56, um IC95 bootstrap que não cruza zero já
  garante significância; o piso de |rho|≥0.30 exige **relevância material** (correlação ao menos
  moderada), evitando declarar GO em cima de um efeito estatisticamente detectável porém pequeno
  demais para sustentar um score (BLK-LTV-04). É defensável e alinhado ao espírito da DEC-008
  (não forçar GO). O relatório declara este limiar EXPLICITAMENTE e lista quais pares o atingem.
- **NO-GO é resultado legítimo** — a função NUNCA levanta exceção por dar NO-GO; o relatório
  apresenta TODOS os 21 pares honestamente (rho, IC, p, N), independentemente do veredito.
