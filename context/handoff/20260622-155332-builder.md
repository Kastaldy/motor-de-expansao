## O que foi feito

### 1. `src/motor_expansao/dimensionamento/excel_export.py` (NOVO)

Função pública `gerar_excel_viabilidade(result: ViabilidadePontoResult, serie: list[dict], *, nome_ponto: str = "") -> bytes`.

4 abas implementadas:
- **Resumo**: 15 KPIs de `ViabilidadePontoResult`/`ViabilidadeResult`, zebra cinza, cabeçalho turquesa, larguras A=35/B=22.
- **DRE**: waterfall steady-state (Faturamento Bruto → Deduções → Receita Líquida → PIS/COFINS/ISS → Receita pós-impostos → Custos operacionais totais → EBITDA → IR/CSLL → Lucro Líquido). Custos derivados de `receita_pos_impostos − ebitda_mensal` (não expostos no dataclass).
- **Sensibilidade**: pivot `alunos × fator_aluguel` com cor célula a célula (`_VERDE_CLR` ≥10%, `_AMARELO_CLR` 0-10%, `_VERMELHO_CLR` <0%). Guard para `grade` vazia.
- **Curva**: 60 linhas de `serie` (mes, alunos_balcao, faturamento_mensal, ebitda_mensal, fcf_acumulado). Guard para `serie` vazia.

ZERO I/O de disco: usa `BytesIO` exclusivamente. `openpyxl` usa `/tmp` internamente durante compressão zip (comportamento normal).

### 2. `src/motor_expansao/dashboard/pages.py`

Bloco inserido entre linha 3677 (último `st.plotly_chart`) e linha 3679 (`# --- Secao 9`):

```python
# --- Secao 8b: exportar Excel ---
try:
    from motor_expansao.dimensionamento.excel_export import gerar_excel_viabilidade
    _nome_ponto = f"{lat:.6f}, {lng:.6f}"
    _excel_bytes = gerar_excel_viabilidade(result, _serie, nome_ponto=_nome_ponto)
    st.download_button(
        label="Exportar Excel",
        data=_excel_bytes,
        file_name=f"viabilidade_{lat:.4f}_{lng:.4f}.xlsx",
        mime="application/vnd.openxmlformats-officedocument.spreadsheetml.sheet",
        help="Baixar simulador de viabilidade em formato Excel (.xlsx) com 4 abas: ...",
    )
except Exception:
    st.caption("Export Excel indisponivel.")
```

Import lazy + try/except: fallback gracioso em caso de erro.

Nota: `render_viabilidade_ponto` não tem parâmetro `nome_ponto`, então usamos `f"{lat:.6f}, {lng:.6f}"` diretamente. A `_serie` já está disponível no escopo (linha 3509).
