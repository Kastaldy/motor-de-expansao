#### Função 3 — `calcular_residual_no_raio_variavel`
```python
def calcular_residual_no_raio_variavel(base: pd.DataFrame) -> pd.DataFrame:
```
- `out = base.copy()`.
- `alunos = pd.to_numeric(out["alunos_reais"], errors="coerce")`.
- `out["flag_viavel"] = (alunos >= PISO_VIABILIDADE_ALUNOS).astype(int)` (1=viável≥2k, 0=inviável; NaN de alunos → 0, documentado).

#### Função 4 — `teste_b_discriminacao`
```python
def teste_b_discriminacao(base: pd.DataFrame, *, rng_seed: int = SEED) -> dict:
```
- Trabalha só sobre linhas com `flag_viavel` definido E `alunos_reais` finito E `score_oportunidade_residual` finito (`hex_match_ok`). Chama isso de `work`.
- **Feature principal:** `score_oportunidade_residual` (hex).
- **Baseline:** combina `pop_captacao_fixo_1p5 * renda_per_capita_hex` num único score escalar (produto, como o BO especifica `pop_captacao_fixo_1p5 × renda_per_capita`). Onde algum fator é NaN → linha cai do baseline; reportar `n_baseline`.
- **AUC:** `roc_auc_score(y=flag_viavel, score)`. Como AUC só é definida com ambas as classes presentes, guard: se `y.nunique() < 2` → retornar dict com `veredito="INDEFINIDO"` e AUCs `nan` (NÃO levantar).
- **Anti-circularidade (penetração LOO regional) — exigência do BO/critério de aceite:** além do residual cru, computar uma feature `penetracao_regional_loo` = para cada unidade, a MÉDIA da `penetracao_observada` das OUTRAS unidades do mesmo cluster de UF (`uf`), excluindo a própria (leave-one-unit-out estrito). Reportar a AUC dessa feature também (`auc_penetracao_loo`). Implementar com groupby por `uf`: `soma_grupo - valor_i) / (n_grupo - 1)`; grupos com `n_grupo==1` → NaN (sem vizinho para estimar; não vaza desfecho próprio). Esta é a feature que o `test_guardrail_anti_circular_penetracao` verifica (a unidade-alvo NUNCA entra na sua própria média).
- **IC bootstrap (N=1000):** reamostrar índices com reposição (`np.random.default_rng(rng_seed)`), recomputar AUC de cada feature; `ic95 = (percentil 2.5, percentil 97.5)`. Bootstrap só sobre amostras que mantêm ambas as classes; descartar reamostra degenerada (classe única) e seguir até completar N válidas ou um teto de tentativas (ex.: `10*N_BOOTSTRAP`) — registrar `n_bootstrap_validos`.
- **p-valor de permutação (N=500):** permutar `flag_viavel`, recomputar AUC da feature residual; `p = (1 + #{auc_perm >= auc_obs}) / (N_perm + 1)`.
- **delta_auc** = `auc_residual - auc_baseline`.
- **Veredito GO/NO-GO:** `"GO"` se `auc_residual > AUC_GO_MIN` E `ic_inferior_residual > AUC_IC_INFERIOR_MIN`; senão `"NO-GO"`. NO-GO é resultado válido (não forçar).
- **Retorno (dict):** `{ "n": int, "n_viaveis": int, "n_inviaveis": int, "auc_residual": float, "auc_baseline": float, "auc_penetracao_loo": float, "delta_auc": float, "ic95_residual": (lo, hi), "ic95_baseline": (lo, hi), "p_permutacao": float, "n_bootstrap_validos": int, "veredito": str }`.

#### Função 5 — `teste_c_decomposicao_variancia`
```python
def teste_c_decomposicao_variancia(base: pd.DataFrame, *, min_celula: int = N_CELULA_MIN) -> dict:
```
- **Resposta:** `y = log(penetracao_observada_loo)` onde `penetracao_observada_loo` = penetração LOO regional por UF-cluster (mesma lógica anti-circular do Teste B: média das OUTRAS unidades do cluster). Filtrar `y` finito e `>0` antes do log.
- **Efeitos / design matrix (numpy puro, SEM dependência nova):**
  - `regiao` = `_MACRO_REGIAO_POR_UF[uf]` (dummies one-hot, drop-first p/ evitar colinearidade).
  - `marca` = dummies de `marca` (ultra/engenharia_do_corpo/skyfit, drop-first).
  - `dominio` = `n_mesma_marca_no_raio` (contínua).
  - Intercepto.
- **Método:** OLS via `np.linalg.lstsq` (estável, sem scipy). **Variância explicada por componente via ANOVA-sequencial (SS tipo I):** ajustar modelos aninhados na ordem `intercepto → +regiao → +marca → +dominio`; a SS de cada bloco = `SS_res(modelo_anterior) - SS_res(modelo_com_bloco)`; variância explicada = `SS_bloco / SS_total`. Reportar `var_explicada_regiao`, `var_explicada_marca`, `var_explicada_dominio`, `r2_total`.
- **Coeficiente de domínio + IC:** do modelo completo, `coef_dominio` e IC95 via erro-padrão clássico OLS (`sigma2 * (XᵀX)⁻¹` diagonal; `t≈1.96` aproximação normal, documentado como aproximação com N pequeno). Só reportar IC se `n_efetivo >= min_celula` e `XᵀX` invertível (try/except `np.linalg.LinAlgError` → IC `nan`, flag).
- **MixedLM (statsmodels) é OPCIONAL e provavelmente indisponível** — NÃO adicionar dependência. Tentar `import statsmodels` em try/except; se ausente OU não converge → fallback gracioso para o OLS+dummies acima, registrando `metodo="ols_dummies"` (vs `"mixedlm"`). Default e caminho testado = OLS. (Decisão D4.)
- **Penetração-base líquida de domínio:** predição do modelo para `n_mesma_marca_no_raio = 0`, por macro-região (set as outras dummies de marca p/ a marca de referência), back-transformada de log → penetração; reportar por macro-região com flag `n_celula_insuficiente` quando a célula tem `< min_celula`.
- **Uplift de domínio:** `exp(coef_dominio) - 1` (uplift multiplicativo de penetração por unidade adicional de marca própria no catchment) + IC, com caso Engenharia-Sul anotado (contagem de unidades engenharia em Sul).
- **Retorno (dict):** `{ "metodo": str, "n_efetivo": int, "r2_total": float, "var_explicada_regiao": float, "var_explicada_marca": float, "var_explicada_dominio": float, "coef_dominio": float, "ic95_dominio": (lo,hi), "uplift_dominio_pct": float, "penetracao_base_por_regiao": {regiao: {"valor": float, "n": int, "n_celula_insuficiente": bool}}, "celulas_insuficientes": [...] }`.
- Guard: se `n_efetivo < min_celula` global → retornar dict com `metodo="indefinido"` e componentes `nan` (não levantar).

## Decisões técnicas

- **D1 — AUC via `sklearn.metrics.roc_auc_score` (disponível), não implementação manual.** Já é dep do projeto (`aderencia.py` usa sklearn). Mais robusto que ROC manual. IC por bootstrap próprio (sklearn não dá IC).
- **D2 — Baseline do Teste B = `pop_captacao_fixo_1p5 * renda_per_capita_hex` (produto escalar).** O BO especifica "pop+renda em raio fixo"; produto é um score único monotônico razoável para ranking (não é regressão). Documentar que é proxy de ranking, não modelo. Alternativa rejeitada: 2 features → exigiria um classificador (vazamento/overfit com N pequeno).
- **D3 — Penetração regional LOO por `uf` (não macro-região) no Teste B**, e por macro-região colapsada SÓ no Teste C (onde células ralas quebram a regressão). Razão: a anti-circularidade do Teste B é por-unidade (excluir a própria); UF é o cluster natural; macro-região é para a decomposição de variância. Grupos `n==1` → NaN (sem vazamento). **Esta é a defesa anti-circular exigida no critério de aceite.**
- **D4 — Teste C por OLS+dummies com ANOVA SS tipo I (numpy `lstsq`), NÃO MixedLM.** `statsmodels` não está garantido no ambiente (não importado em nenhum módulo do projeto; não adicionar dependência — guardrail loop-safe "só o que já está no projeto"). MixedLM com grupos pequenos/desbalanceados notoriamente não converge (risco do BO). Caminho default e testado = OLS; tentativa de MixedLM fica em try/except gracioso registrando `metodo`. SS tipo I é sensível à ordem → ordem fixa e documentada `regiao → marca → dominio` (domínio entra por último, medindo o que sobra após região+marca — exatamente o que o BO quer: não deixar domínio vazar para região).
- **D5 — Bootstrap descarta reamostras com classe única** (AUC indefinida) e conta `n_bootstrap_validos`; teto de tentativas evita loop infinito quando uma classe é minúscula. `score_oportunidade_residual` é zero-inflado → muitas unidades terão score 0; AUC ainda é computável (empates tratados pelo `roc_auc_score`). Documentar o zero-inflation no relatório.
- **D6 — Mapa `_MACRO_REGIAO_POR_UF` LOCAL no módulo**, não importar `REGIAO_POR_UF` do M1 (`pipelines/m1/base_h3_brasil.py`) — evita acoplamento READ-ONLY→M1. Colapso CO+Norte num único bucket `CO_Norte` por células ralas (risco explícito do BO: SP=47% do N; Engenharia concentrada no Sul).
- **D7 — `h3.latlng_to_cell(lat, lng, 7)` (API v4, confirmada h3 4.5.0)**, import lazy dentro da função. Coords inválidas → try/except por linha → `hex_match_ok=False` (não derruba o pipeline).
- **D8 — Veredito GO/NO-GO honesto:** `AUC > 0.55 E IC_inferior > 0.50`. NO-GO e INDEFINIDO (classe única) são resultados VÁLIDOS — nunca forçar GO. Replica a disciplina de `aderencia.py` (NO-GO é esperado).
- **D9 — `oferta_efetiva_disponivel` é do hex H3 (~1 km²), NÃO do catchment variável da unidade** — usar como PROXY e declarar a limitação no relatório (risco do BO). A penetração do Teste C usa `pop_captacao_variavel` (do raio variável real), que é o sinal correto.
- **D10 — Anti-PII em cada DF antes de qualquer retorno/escrita** (`assert_sem_pii`). `unidade` NÃO é PII (rótulo de loja, já validado em `base_multirede`); nomes nunca listados nominalmente no relatório — só agregados (médias por marca/região).
