### `src/motor_expansao/dimensionamento/features_exogenas.py` (CRIAR)
- `ResultadoModeloFeatures` (dataclass) — métricas LOO honestas por feature_set + `.go`.
- `_loo_ridge_multifeature(X, y, alpha_grid)` — **LOO-CV Ridge reimplementado do zero** (NÃO importa
  de `aderencia.py`): varre `ALPHA_GRID`, seleciona alpha por MENOR `rmse_loo_log`, R² LOO em dois
  espaços (log + pagantes via exp), modelo final p/ coef/intercepto/`r2_insample`. Espelha fielmente
  a lógica de `aderencia._r2_loo_para_alpha` + a varredura de `calibrar_aderencia`. Validado: o
  baseline pop+renda reproduz EXATAMENTE `r2_loo_log = -0.0134` do BLK-DIM-01R.
- `derivar_n_concorrentes_raio(df_unidades, df_concorrentes, raio_km=1.5)` — Haversine numpy
  vetorizado por unidade; filtra `flag_coord_valida==True & flag_duplicado_rede_coord==False`;
  unidade sem lat/lng → NaN (não 0). PURA, testável offline.
- `derivar_features_censo(df_unidades, geo_base_dir, raio_km, setores_loader=None)` — espelha o loop
  cache-por-UF de `catchment_batch`; reusa `analisar_ponto_censitario_setores` (INTOCADO) e extrai
  `densidade_pop_catchment_hab_km2` (= `result["densidade_pop_raio_hab_km2"]`),
  `renda_responsavel_media_catchment` (média ponderada de `renda_per_capita_setor_2022_calibrada`
  por `pop_total_setor_2022` no frame `setores_intersectados`), + `pop_total_raio`/`n_setores`
  (auditoria). Imports lazy do dashboard/geo. I/O real → não chamado em teste.
- `montar_df_features(...)` — merge maduras←catchment[unidade,lat,lng]; `dropna(lat,lng)` (N=53);
  junta n_conc + features censo por unidade.
- `comparar_modelos_aderencia(df_features, feature_sets=FEATURE_SETS, limiar_r2=0.05)` — deriva
  log_pop/log_renda/n_conc/log1p(densidade)/log(renda_resp), roda `_loo_ridge_multifeature` por set,
  remove NaN/±inf SÓ por set, `ValueError` se n < `N_MIN_CALIBRACAO`. 3 feature_sets canônicos
  (`baseline_pop_renda`, `A_pop_renda_conc`, `B_pop_renda_conc_dens_rendaresp`).
- `escrever_relatorio_features(...)` — materializa `data/analysis/features_aderencia.md` (gitignored):
  tabela + delta vs baseline + correlações + confounds + veredito consolidado. NÃO chamado em teste.
- `main()` (`if __name__`) — lê os 3 parquets de `data/staging/`, monta, compara, escreve relatório.

**Critério de materialidade (des-circular):** GO MATERIAL = `r2_loo_log > 0.05` **E** `> baseline +
