### Passo 1 — Criar `src/motor_expansao/demanda_revelada/validacao.py`

Funções públicas (todas READ-ONLY, sem escrita em artefatos M1):

```
carregar_par_validacao(
    demanda_path: Path = DEMANDA_DEFAULT,
    mercado_path: Path = MERCADO_DEFAULT,
    priorizados_path: Path = PRIORIZADOS_DEFAULT,
) -> pd.DataFrame
```
- Carrega `demanda_revelada_h3.parquet` (colunas: `hex_id`, `membros`).
- Carrega `hexagonos_mercado_mapeado.parquet` com guard de existência (columns: `hex_id`, `score_oportunidade_residual`, `oferta_efetiva_disponivel`, `uf`).
- Carrega `brasil_priorizados.parquet` com guard de existência (columns: `hex_id`, `uf`, `score_priorizacao`); deriva `top_m1_20pct = True` para os hexes presentes.
- Faz `inner join` demanda × mercado em `hex_id` (preserva só hexes com ambos os lados); depois `left join` com priorizados para o flag `top_m1_20pct`.
- Retorna DataFrame com colunas: `hex_id`, `membros`, `score_oportunidade_residual`, `oferta_efetiva_disponivel`, `uf`, `top_m1_20pct`.
- Validação anti-PII: nenhuma coluna de `COLUNAS_PII_PROIBIDAS` pode estar no resultado.

```
calcular_spearman_ic(
    df: pd.DataFrame,
    col_x: str,
    col_y: str,
    n_boot: int = 9999,
    seed: int = 42,
) -> dict[str, float]
```
- Usa `scipy.stats.spearmanr(df[col_x], df[col_y])` para rho e p-valor.
- IC 95% via `scipy.stats.bootstrap` com `paired=True` e `statistic=lambda a, b: spearmanr(a, b).statistic` (ou fórmula de Fisher se bootstrap falhar por N pequeno: `tanh(arctanh(rho) ± 1.96/sqrt(N-3))`).
- Retorna `{"rho": float, "pvalor": float, "ic_low": float, "ic_high": float, "n": int}`.

```
mapear_quadrantes(
    df: pd.DataFrame,
    limiar_residual: float | None = None,
    limiar_demanda: float | None = None,
) -> pd.DataFrame
```
- `limiar_residual` = mediana de `score_oportunidade_residual` se `None`.
- `limiar_demanda` = mediana de `membros` se `None`.
- Adiciona coluna `quadrante`: `Q1` (residual≥limiar E membros≥limiar), `Q2` (residual≥limiar E membros<limiar), `Q3` (residual<limiar E membros≥limiar), `Q4` (residual<limiar E membros<limiar).
- Retorna df com coluna `quadrante` adicionada.

```
calcular_divergencias(df: pd.DataFrame) -> dict[str, pd.DataFrame]
```
- `q1_fora_top20`: hexes Q1 com `top_m1_20pct=False`, ordenados por `membros` desc.
- `top20_fora_q1`: hexes `top_m1_20pct=True` com quadrante ≠ Q1, ordenados por `score_oportunidade_residual` desc.
- Retorna dict com as duas chaves.

```
gerar_relatorio_validacao(
    df: pd.DataFrame,
    spearman_primario: dict,
    spearman_secundario: dict,
    limiar_residual: float,
    limiar_demanda: float,
    divergencias: dict[str, pd.DataFrame],
    destino: Path = RELATORIO_DEFAULT,
) -> str
```
- Gera o Markdown estruturado (7 seções do D4) como string.
- Escreve em `destino` se fornecido (padrão `data/reports/demanda_revelada_validacao.md`).
- Retorna o conteúdo gerado.

```
salvar_quadrantes_parquet(
    df: pd.DataFrame,
    destino: Path = QUADRANTES_DEFAULT,
) -> None
```
- Seleciona colunas: `hex_id`, `membros`, `score_oportunidade_residual`, `oferta_efetiva_disponivel`, `uf`, `quadrante`, `top_m1_20pct`.
- Valida anti-PII antes de salvar.
- Salva em `data/staging/quadrantes_demanda_residual.parquet`.

```
executar_validacao_completa(
    demanda_path, mercado_path, priorizados_path,
    relatorio_path, quadrantes_path,
    salvar_quadrantes: bool = True,
) -> dict
```
- Orquestra todos os passos acima.
- Retorna dict com: `n_hexes_join`, `spearman_primario`, `spearman_secundario`, `contagem_quadrantes`, `n_q1_fora_top20`, `n_top20_fora_q1`.

**Constantes de caminho no topo do módulo:**

## Riscos técnicos

1. **`hexagonos_mercado_mapeado.parquet` ausente localmente** — arquivo gitignored; função `carregar_par_validacao` deve levantar `FileNotFoundError` claro com mensagem de regeneração. Os testes usam fixture sintética e nunca dependem do arquivo real.

2. **N do join pode ser menor que o esperado (~16.575)** — o inner join descarta hexes sem cobertura de demanda revelada (~99% do universo); cobrir isso como caveat obrigatório no relatório.

3. **IC 95% via bootstrap pode ser lento** — se o join resultar em N > 10.000, usar a fórmula analítica de Fisher (`tanh(arctanh(rho) ± 1.96/sqrt(N-3))`) como alternativa rápida; documentar a escolha no código.

4. **DEC-009 — escorregamento de escopo** — não usar `membros` como input em regressão nem como ajuste de score. O módulo é somente correlação + quadrante; proibição registrada no relatório (Seção 7).

5. **Anti-PII** — o DataFrame de saída (`carregar_par_validacao`) não pode ter colunas de `COLUNAS_PII_PROIBIDAS`. Adicionar `_assert_sem_pii` (importar de `contrato.py`) após o join para garantia.
