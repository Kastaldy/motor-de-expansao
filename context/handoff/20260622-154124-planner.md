def gerar_excel_viabilidade(
    result: ViabilidadePontoResult,

    *,

### Estrutura das 4 abas

#### Aba 1 — "Resumo"

Cabeçalho (linha 1): fundo turquesa `#00BFB3`, texto branco, negrito, `"ULTRA Academia — Simulador de Viabilidade"`.
Linha 2: `nome_ponto` (se fornecido), fundo cinza claro.
Linha 3: vazia (separador).

Campos (a partir da linha 4), 2 colunas (Indicador | Valor):

| Indicador | Campo de `ViabilidadePontoResult` / `ViabilidadeResult` | Formato |
|---|---|---|
| Ponto analisado | `f"{result.lat:.6f}, {result.lng:.6f}"` | texto |
| Metragem (m²) | `result.m2` | número inteiro |
| Aluguel pedido (R$/mês) | `result.aluguel_pedido` | `R$ #,##0.00` |
| Demanda premissa (alunos) | `result.demanda_premissa` | número inteiro |
| Faturamento bruto/mês | `result.viabilidade.faturamento_mensal_steady` | `R$ #,##0.00` |
| Receita líquida/mês | `result.viabilidade.receita_liquida` | `R$ #,##0.00` |
| EBITDA/mês | `result.viabilidade.ebitda_mensal` | `R$ #,##0.00` |
| Margem EBITDA | `result.viabilidade.margem_ebitda_pct` | `0.0%` |
| Payback (meses) | `result.viabilidade.payback_meses` (se `inf` → "Não atingido") | texto/número |
| ROIC anual | `result.viabilidade.roic_anual` | `0.0%` |
| Lucro líquido/mês | `result.viabilidade.lucro_liquido_mensal` | `R$ #,##0.00` |
| Alunos break-even | `result.alunos_breakeven` (se `inf` → "Inviável") | texto/número |
| Aluguel-teto | `result.aluguel_teto_calculado` | `R$ #,##0.00` |
| Viável? | `"Sim" if result.viabilidade.flag_viavel else "Não"` | texto |
| Fonte da demanda | `result.demanda_fonte` | texto |

Linhas alternadas com fundo `_CINZA_CLR` (zebra). Coluna A width=35, coluna B width=22.

#### Aba 2 — "DRE"

Cabeçalho (linha 1): fundo turquesa, texto branco, `"DRE Steady-State"`.

Tabela linha a linha do DRE, colunas (Linha DRE | R$/mês | % Faturamento):

| Linha | Campo | Cálculo derivado |
|---|---|---|
| Faturamento Bruto | `viab.faturamento_mensal_steady` | 100% |
| (−) Deduções | `viab.faturamento_mensal_steady − viab.receita_liquida` | derivado |
| Receita Líquida | `viab.receita_liquida` | derivado |
| (−) PIS/COFINS/ISS | `viab.receita_liquida − viab.receita_pos_impostos` | derivado |
| Receita pós-impostos | `viab.receita_pos_impostos` | derivado |
| (−) Custos variáveis | `viab.receita_pos_impostos − viab.ebitda_mensal − (viab.faturamento_mensal_steady − viab.faturamento_mensal_steady)` — **ver nota** | derivado |
| (−) Custos fixos (pessoal+outros+aluguel) | derivado | derivado |
| **EBITDA** | `viab.ebitda_mensal` | `margem_ebitda_pct` |
| (−) IR/CSLL | `viab.ebitda_mensal − viab.lucro_liquido_mensal` | derivado |
| **Lucro Líquido** | `viab.lucro_liquido_mensal` | derivado |

**Nota sobre custos**: `ViabilidadeResult` não expõe `custos_variaveis` e `custos_fixos` separadamente. O Builder deve derivar:
- `custos_op_total = viab.receita_pos_impostos − viab.ebitda_mensal`
- `ir_csll = viab.ebitda_mensal − viab.lucro_liquido_mensal`
- Exibir em 1 linha "Custos operacionais totais" = `custos_op_total` (ao invés de separar variável/fixo, que não estão expostos no dataclass).

Formatação: valores monetários com `_FMT_BRL`; percentuais com `_FMT_PCT`; linha EBITDA em negrito; linha de total com borda dupla no topo.

#### Aba 3 — "Sensibilidade"

Cabeçalho: fundo turquesa, `"Grade de Sensibilidade — Margem EBITDA (alunos x aluguel)"`.

Fonte dos dados: `result.grade_sensibilidade` (DataFrame com colunas `alunos`, `aluguel`, `fator_aluguel`, `margem_liq`, `viavel`, `payback`).

Montar como pivot: `alunos` no eixo linha, `fator_aluguel` no eixo coluna, valor = `margem_liq`.

Implementação:
```python
grade = result.grade_sensibilidade
pivot = grade.pivot_table(index="alunos", columns="fator_aluguel", values="margem_liq", aggfunc="first")
```

- Linha de cabeçalho das colunas: `f"x{fator:.1f}"` (ex: "x0.6", "x0.8", ...).
- Coluna de índice: "Alunos" (cabeçalho).
- Formatação condicional de cada célula de valor:
  - `margem_liq >= 0.10` → fundo `_VERDE_HEX` (ou verde claro `FF90EE90`)
  - `0 <= margem_liq < 0.10` → fundo `_AMARELO_HEX`
  - `margem_liq < 0` → fundo `_VERMELHO_HEX` (vermelho claro `FFFFC0C0` para não esconder texto)
  - Valor formatado como `0.0%`.
- Se `grade` estiver vazia ou for `None`: aba com mensagem "Grade não disponível".

#### Aba 4 — "Curva"

Cabeçalho: fundo turquesa, `"Projeção Financeira — 60 meses"`.

Fonte: parâmetro `serie: list[dict]` (60 dicts com chaves: `mes`, `alunos_balcao`, `faturamento_mensal`, `ebitda_mensal`, `fcf_acumulado`).

Cabeçalho da tabela (linha 2, negrito):

| Mês | Alunos Balcão | Faturamento (R$) | EBITDA (R$) | FCF Acumulado (R$) |
|---|---|---|---|---|

- 60 linhas de dados (mes 1 a 60).
- Formatação: `alunos_balcao` como inteiro; demais monetários com `_FMT_BRL`.
- Zebra: linhas pares com `_CINZA_CLR`.
- Se `serie` estiver vazia: aba com mensagem "Série não disponível".

### Estrutura completa do módulo

```python
"""Export do simulador de viabilidade para Excel (BLK-DIM-22).

READ-ONLY sobre o M1: nao recalcula score_priorizacao, pesos nem artefatos (DEC-001).
Sem I/O de disco: usa BytesIO exclusivamente.
"""
from __future__ import annotations

from io import BytesIO
from typing import TYPE_CHECKING

import openpyxl
from openpyxl.styles import Alignment, Font, PatternFill
from openpyxl.utils import get_column_letter

if TYPE_CHECKING:
    from motor_expansao.dimensionamento.viabilidade_ponto import ViabilidadePontoResult

# --- Paleta Ultra ---
_TURQUESA_HEX = "FF00BFB3"
_BRANCO_HEX   = "FFFFFFFF"
_CINZA_ESC    = "FF2E3040"
_CINZA_CLR    = "FFF5F5F5"
_VERDE_CLR    = "FF90EE90"
_AMARELO_CLR  = "FFFFFF99"
_VERMELHO_CLR = "FFFFC0C0"
_FONTE_PADRAO = "Calibri"
_FMT_BRL      = 'R$ #,##0.00'
_FMT_PCT      = '0.0%'

def _fill(hex_argb: str) -> PatternFill:
    return PatternFill(fill_type="solid", fgColor=hex_argb)

def _header_font(bold: bool = True) -> Font:
    return Font(name=_FONTE_PADRAO, bold=bold, color=_BRANCO_HEX, size=12)

def _body_font(bold: bool = False) -> Font:
    return Font(name=_FONTE_PADRAO, bold=bold, color=_CINZA_ESC, size=10)

def _set_col_width(ws, col_idx: int, width: float) -> None:
    ws.column_dimensions[get_column_letter(col_idx)].width = width

def _write_aba_resumo(wb, result: "ViabilidadePontoResult", nome_ponto: str) -> None: ...
def _write_aba_dre(wb, result: "ViabilidadePontoResult") -> None: ...
def _write_aba_sensibilidade(wb, result: "ViabilidadePontoResult") -> None: ...
def _write_aba_curva(wb, serie: list[dict]) -> None: ...

def gerar_excel_viabilidade(
    result: "ViabilidadePontoResult",
    serie: list[dict],
    *,
    nome_ponto: str = "",
) -> bytes:
    """Gera arquivo .xlsx em memoria com 4 abas do simulador de viabilidade.

    READ-ONLY sobre o M1 (nao recalcula score_priorizacao nem artefatos).
    Sem I/O de disco — usa BytesIO exclusivamente.

    Parameters
    ----------
    result:
        Resultado de analisar_viabilidade_ponto().
    serie:
        Lista de 60 dicts de gerar_serie_mensal() (chaves: mes, alunos_balcao,
        faturamento_mensal, ebitda_mensal, fcf_acumulado).
    nome_ponto:
        Nome opcional do ponto/imovel para o cabecalho do Excel.

    Returns
    -------
    bytes
        Conteudo binario do arquivo .xlsx. NUNCA escreve em disco.
    """
    wb = openpyxl.Workbook()
    wb.remove(wb.active)  # remove aba padrao vazia

    _write_aba_resumo(wb, result, nome_ponto)
    _write_aba_dre(wb, result)
    _write_aba_sensibilidade(wb, result)
    _write_aba_curva(wb, serie)

    buf = BytesIO()
    wb.save(buf)
    return buf.getvalue()


__all__ = ["gerar_excel_viabilidade"]
```

def test_sem_escrita_em_disco(tmp_path, monkeypatch):
    """CA-12e: gerar_excel_viabilidade nao escreve em disco.

    Monitora builtins.open — qualquer chamada de escrita de arquivo no
    diretorio do sistema durante a execucao falha o teste.
    (A funcao usa BytesIO; o monkeypatch garante que isso nao muda.)
    """
    import builtins
    original_open = builtins.open

    written_files: list[str] = []

    def _guarded_open(file, mode="r", *args, **kwargs):
        if isinstance(file, str) and "w" in str(mode):
            written_files.append(str(file))
        return original_open(file, mode, *args, **kwargs)

    monkeypatch.setattr(builtins, "open", _guarded_open)

    _ = gerar_excel_viabilidade(_RESULT, _SERIE)
    assert written_files == [], f"Escrita em disco detectada: {written_files}"

## 6. Riscos e mitigações

| Risco | Mitigação |
|---|---|
| `ViabilidadeResult` não expõe `custos_variaveis`/`custos_fixos` separados | Agrupar em "Custos operacionais totais" = `receita_pos_impostos − ebitda_mensal` |
| `result.grade_sensibilidade` pode ser `None` ou vazia | Guard `if grade is not None and not grade.empty` antes de pivotar; aba com mensagem se ausente |
| `serie` pode ser lista vazia | Guard `if serie` antes de iterar; aba Curva com mensagem se vazia |
| `payback_meses == float('inf')` | Converter para string "Não atingido" antes de escrever na célula |
| `alunos_breakeven == float('inf')` | Converter para string "Inviável" |
| mypy pode reclamar do TYPE_CHECKING pattern | Usar `from __future__ import annotations` + `TYPE_CHECKING` para importação lazy do tipo |
| Coloração condicional da aba Sensibilidade com `openpyxl` | Usar `PatternFill` célula a célula (não `ConditionalFormatting`, mais simples e determinístico) |
