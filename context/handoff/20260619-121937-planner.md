### 1. Helper de detecção de URL (string pura, sem rede)
Adicionar, logo acima de `render_coord_search_sidebar` (perto de `_render_endereco_fallback_link`,
~681), uma função utilitária local:

```python
def _parece_link(raw: str) -> bool:
    """True se o texto começa com http:// ou https:// (heurística de 'isto é uma URL')."""
    return raw.lower().startswith(("http://", "https://"))
```

E uma segunda função que reconheça um **link curto** do Maps (que NÃO traz coordenada na string):

```python
def _e_link_curto_maps(raw: str) -> bool:
    """True para encurtadores do Maps (maps.app.goo.gl, goo.gl/maps) — não resolvíveis offline."""
    low = raw.lower()
    return ("maps.app.goo.gl" in low) or ("goo.gl/maps" in low)
```

(Ambas são puras, sem I/O. Servem só para rotear a cascata e escolher a mensagem correta.)

### 2. Inserir o caminho de link Maps na cascata de `render_coord_search_sidebar`
A cascata final (depois de `raw = raw.strip()`, ~728) passa a ser, NESTA ordem:

1. **Numérico (INTOCADO):** `result = parse_coordinate_input(raw); if result is not None: return result`.
   Bloco atual das linhas ~730–733 permanece byte-a-byte.

2. **Link do Maps (NOVO — offline, regex pura):** só entra se `_parece_link(raw)` for True.
   - Se `_e_link_curto_maps(raw)` for True → **(Opção A, MVP)** exibir mensagem clara pedindo URL
     longa ou coordenada e `return None` (NÃO cair no Nominatim, que tentaria resolver
     `"maps.app.goo.gl/..."` como endereço literal e devolveria None silencioso). Texto sugerido:
     `st.warning("Link curto do Google Maps detectado. Abra o link, copie a URL longa (que contém a coordenada) ou cole a coordenada lat,lng diretamente.")`
   - Caso contrário (URL longa): import lazy `from motor_expansao.api.maps_geocoder import extract_any_coord`
     (mesmo padrão de `_resolve_viab_ponto`, ~3058), extrair `lat, lng = extract_any_coord(raw)`.
     - Se `lat is not None and lng is not None`: `validated = _validate_brazil_bbox(float(lat), float(lng))`
       (já importado em `pages.py:87`); se `validated is not None: return validated`.
     - Se a extração falhou (par `None`) OU a validação de bbox rejeitou (fora do Brasil):
       exibir mensagem clara e `return None`. Texto sugerido:
       `st.warning("Não foi possível extrair uma coordenada do Brasil deste link do Maps. Use a URL longa (com o pino) ou cole a coordenada lat,lng.")`
   - **Importante:** quando `_parece_link(raw)` é True, o fluxo NÃO cai no caminho de endereço
     (passo 3) nem no fallback genérico — um link nunca deve ser enviado ao Nominatim como
     endereço literal. O `return None` dos sub-casos acima encerra a função.

3. **Endereço livre (INTOCADO):** bloco atual das linhas ~735–748 permanece byte-a-byte
   (`resolve_endereco_http` via try/except + `_render_endereco_fallback_link`). Só é alcançado
   quando `_parece_link(raw)` é False (texto não-URL que não casou no numérico).

Estrutura de controle resultante (esqueleto, o Builder ajusta o corpo):
```python
result = parse_coordinate_input(raw)          # 1 — intocado
if result is not None:
    return result

if _parece_link(raw):                          # 2 — NOVO, offline
    if _e_link_curto_maps(raw):
        st.warning(... pedir URL longa ou coordenada ...)
        return None
    from motor_expansao.api.maps_geocoder import extract_any_coord
    lat, lng = extract_any_coord(raw)
    if lat is not None and lng is not None:
        validated = _validate_brazil_bbox(float(lat), float(lng))
        if validated is not None:
            return validated
    st.warning(... link sem coordenada do Brasil ...)
    return None

# 3 — endereço (intocado)
try:
    from motor_expansao.api.maps_geocoder import resolve_endereco_http
    resolved = resolve_endereco_http(raw, timeout=6.0, cache_dir=_GEOCODE_CACHE_DIR)
except Exception:
    resolved = None
if resolved is not None:
    return resolved
_render_endereco_fallback_link(raw)
return None
```

### 4. DECISÃO DE GATE — links curtos (`maps.app.goo.gl` / `goo.gl/maps`)
**O Builder só implementa a opção que o humano aprovar neste gate.**

- **Opção A (RECOMENDADA para o MVP — é o que o plano acima já descreve):**
  apenas URL longa via `extract_any_coord` (regex offline). Link curto cai em
  `_e_link_curto_maps` → mensagem clara pedindo URL longa ou coordenada. **Sem rede adicional,
  sem nova DEC, sem emenda à DEC-010.** Risco mínimo; o desvio de rede já aprovado (endereço via
  Nominatim) NÃO se expande.

- **Opção B (somente se o humano aprovar — exige emenda à DEC-010):** também seguir o redirect
  HTTP de links curtos para obter a URL longa final (com `!3d/!4d`) e então `extract_any_coord`.
  Delta técnico, pequeno e isolado, se aprovado:
  1. NÃO em `pages.py`: adicionar um helper novo em `maps_geocoder.py` (camada `api`), ex.
     `resolve_short_link(url, *, timeout=6.0) -> str | None`, com `urllib.request` puro
     (`Request` + `urlopen`, lendo `resp.geturl()` / `resp.url` após os redirects), `try/except`
     amplo → `None` em qualquer falha/sem rede, e User-Agent identificável (mesmo padrão de
     `resolve_endereco_http`).
  2. Em `render_coord_search_sidebar`, no ramo `_e_link_curto_maps`: chamar esse helper
     (import lazy), passar a URL final a `extract_any_coord` + `_validate_brazil_bbox`; falha →
     a MESMA mensagem da Opção A (fallback gracioso). Sem cache obrigatório (links curtos são
     efêmeros), mas pode reusar `data/cache/geocode/` se desejado.
  3. Mitigações herdadas da DEC-010 (a)–(f): rede só neste sub-caminho, timeout curto,
     try/except amplo, I/O isolado em `maps_geocoder.py`, import lazy, nota anti-PII (a URL é
     enviada ao Google só para seguir o redirect; nenhum dado persistido além de lat,lng).
  4. **Bloqueio de execução:** a Opção B altera `maps_geocoder.py` (fora do escopo declarado no
     handoff do Orchestrator) e expande o desvio de rede → exige **emenda à DEC-010 registrada no
     CLAUDE.md §8 ANTES do Builder**. Se o humano não aprovar B, o Builder implementa A e nada
     toca `maps_geocoder.py`.

> Recomendação do Planner: **Opção A**. O plano dos passos 1–3 já é a Opção A completa; a Opção B

## Riscos técnicos
- **Ordem da cascata:** link DEVE ser tentado antes do endereço. Se um link cair no Nominatim
  como endereço literal → `None` silencioso. O guard `_parece_link(raw)` (prefixo http/https)
  garante o roteamento e impede o link de chegar ao passo 3.
- **Link curto sem Opção B:** `extract_any_coord` retorna `(None, None)` (não há coordenada na
  string). Sem o ramo `_e_link_curto_maps`, cairia no passo 3 (Nominatim) → mensagem inútil. O
  ramo dedicado emite mensagem específica e correta.
- **Validação de bbox:** `extract_any_coord` devolve par bruto (pode ser fora do Brasil). Aplicar
  `_validate_brazil_bbox` ANTES de retornar (igual à aba de viabilidade, `pages.py:3062`).
- **Regressão:** coordenada e endereço devem funcionar como antes; testes existentes intocados.
- **`@lat,lng` é menos preciso** (centro da câmera). É aceitável como fallback (mesmo
  comportamento de `extract_any_coord` na aba de viabilidade); a precedência `!3d/!4d` > `@` já
  está garantida dentro de `extract_any_coord`.
