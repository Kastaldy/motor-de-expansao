### Investigação dos itens sensíveis (feita na fase de leitura)
1. **F601 — 15× `"pop_total"` repetido** em `tests/integration/test_hex_enrichment_brasil.py`
   (linhas 117/118, 127/128, 137/138, 147/148 e 166–175, 189). Em CADA dict literal o padrão é
   idêntico: `"pop_total": 0.0` aparece PRIMEIRO e logo em seguida `"pop_total": <valor real>`
   (ex.: `1000.0`, `900.0`, `0.0`, `i`). **Regra Python: em dict literal a última chave vence** →
   o valor efetivamente entregue ao fixture já é o SEGUNDO (`pop_total` real). O primeiro
   `"pop_total": 0.0` é código morto, sobrescrito antes mesmo do dict existir. **Remover a primeira
   ocorrência (`"pop_total": 0.0,`) é estritamente invariante**: o dict resultante é idêntico byte-a-byte.
   Nenhuma outra chave está duplicada nesses dicts. → **Correção (remover a 1ª ocorrência), não supressão.**
   Prova exigida no Builder: ver Passo 9.
2. **F821 `pdk` em `pages.py:2518`** — é a anotação `deck: "pdk.Deck"`. O arquivo tem
   `from __future__ import annotations` na linha 1, então TODA anotação é string e **nunca é avaliada
   em runtime** (não há NameError real; o handoff do Orchestrator superestimou esse ponto). Porém
   `pdk` não está importado no módulo (`import pydeck as pdk` só existe em `components.py`), e tanto
   ruff F821 quanto mypy name-defined resolvem a anotação e a marcam como nome indefinido. O `deck`
   é genuinamente um `pdk.Deck` (construído em `components.py` e passado em `pages.py:2663`). →
   **Correção real**: adicionar `import pydeck as pdk` sob bloco `TYPE_CHECKING` (sem custo de import
   em runtime, satisfaz ruff + mypy, intenção da anotação preservada).
3. **B019 `lru_cache` em método — 3× em `ibge_censo.py` (raiz; linhas 292, 363, 381)**: são caches de
   respostas de API (SIDRA renda/pop, Nominatim reverse, busca código IBGE). `ibge_censo.py` (raiz)
   ESTÁ no grafo de produção M1 (importado por `hex_enrichment.py` e `fase1_bi_exports.py` via
   `IBGECenso`). Os métodos usam `self` para despacho a métodos-irmãos que TAMBÉM são `@lru_cache`
   (`_geocodigo_municipio` chama `self._buscar_cod_ibge_por_nome`) e para estado de instância
   (`_municipio_padrao`). Refatorar para funções de módulo mudaria o despacho e arriscaria alterar a
   coleta de dados M1. → **Decisão recomendada: `# noqa: B019` documentado** (justificativa inline:
   cache de resposta de rede, instância efêmera de pipeline, refator muda despacho de produção M1).
   Ver "Recomendação sobre itens sensíveis" no fim.
4. **mypy produção M1:**
   - `hex_enrichment.py:129` e `:233` — `unidades_ultra: list = None` → implicit-Optional. Fix de
     TIPO: `unidades_ultra: list | None = None`. O corpo já faz `unidades_ultra = unidades_ultra or []`

   - `hex_enrichment.py:821,822` — dict-item: `int(melhor["rank_brasil"])` / `int(melhor["rank_uf"])`

     é um `try: from motor_expansao... import` / `except ModuleNotFoundError: from fase1_bi_exports
