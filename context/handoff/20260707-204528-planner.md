#### 1a. Constantes de tier (topo do módulo)

```python
VERSAO_CONTRATO: str = "demanda_premissa_v1"
N_EXTRAPOLACAO_MIN: int = 5   # N < 5 → flag_extrapolacao = True

TIERS: list[dict] = [
    {"tier_label": "<1000",     "metragem_min": 0.0,    "metragem_max": 999.9},
    {"tier_label": "1000-1499", "metragem_min": 1000.0, "metragem_max": 1499.9},
    {"tier_label": "1500-1999", "metragem_min": 1500.0, "metragem_max": 1999.9},
    {"tier_label": "2000-2999", "metragem_min": 2000.0, "metragem_max": 2999.9},
    {"tier_label": ">=3000",    "metragem_min": 3000.0, "metragem_max": float("inf")},
]
```

Nota: `metragem_max=999.9` é o limite inclusivo de exibição; o corte real usa
`metragem < 1000.0` (limite de início do próximo tier). Veja lógica em `_assign_tier`.

#### 1b. `_assign_tier(metragem: float) -> str`

Função privada pura. Lógica:
- `metragem < 1000.0`  → `"<1000"`
- `1000.0 <= metragem < 1500.0` → `"1000-1499"`
- `1500.0 <= metragem < 2000.0` → `"1500-1999"`
- `2000.0 <= metragem < 3000.0` → `"2000-2999"`
- `metragem >= 3000.0` → `">=3000"`

Retorna `str`. Chamada via `df["tier_label"] = df["metragem"].map(_assign_tier)`.

#### 1c. `carregar_ultra(path: Path | str) -> pd.DataFrame`

```python
def carregar_ultra(path: Path | str) -> pd.DataFrame:
```

- Lê `unidades_ultra_performance_hex.parquet` via `pd.read_parquet(path)`.
- Seleciona colunas `["metragem", "alunos_total"]`.
- Dropa linhas onde `metragem` ou `alunos_total` é NaN ou <= 0.
- Renomeia `alunos_total` → `alunos`.
- Converte ambas para `float`.
- Retorna DataFrame com colunas `["metragem", "alunos"]` (somente essas duas).
- **Anti-PII:** nenhuma outra coluna (nome, hex_id, lat, lng) é propagada.

#### 1d. `carregar_eng_corpo(path: Path | str) -> pd.DataFrame`

```python
def carregar_eng_corpo(path: Path | str) -> pd.DataFrame:
```

- Lê `academias_engenharia_do_corpo.xlsx` via `pd.read_excel(path)`.
- Seleciona colunas `["Metragem M²", "Alunos Totais"]`.
- Dropa linhas onde qualquer coluna é NaN ou <= 0.
- Renomeia: `"Metragem M²"` → `"metragem"`, `"Alunos Totais"` → `"alunos"`.
- Converte ambas para `float`.
- Retorna DataFrame com colunas `["metragem", "alunos"]` (somente essas duas).
- **Anti-PII:** nenhuma outra coluna (nome da academia, endereço) é propagada.

#### 1e. `combinar_bases(ultra_df: pd.DataFrame, eng_df: pd.DataFrame) -> pd.DataFrame`

```python
def combinar_bases(ultra_df: pd.DataFrame, eng_df: pd.DataFrame) -> pd.DataFrame:
```

- Valida que ambos os DataFrames têm colunas `["metragem", "alunos"]`.
- `pd.concat([ultra_df, eng_df], ignore_index=True)`.
- Dropa linhas com `metragem <= 0` ou `alunos <= 0` (guard duplo).
- Retorna DataFrame com colunas `["metragem", "alunos"]`.

#### 1f. `calcular_tiers(df: pd.DataFrame, *, n_extrapolacao_min: int = N_EXTRAPOLACAO_MIN) -> pd.DataFrame`

```python
def calcular_tiers(df: pd.DataFrame, *, n_extrapolacao_min: int = N_EXTRAPOLACAO_MIN) -> pd.DataFrame:
```

- Valida que `df` tem `["metragem", "alunos"]`.
- Cria coluna `tier_label` via `df["metragem"].map(_assign_tier)`.
- Para cada tier (na ordem de `TIERS`):
  - Filtra `sub = df[df["tier_label"] == tier["tier_label"]]`.
  - `n = len(sub)`.
  - Se `n == 0`: `p10, p50, p90 = float("nan"), float("nan"), float("nan")`.
  - Se `n > 0`: calcula via `np.percentile(sub["alunos"].to_numpy(dtype=float), [10, 50, 90])`.
  - `flag_extrapolacao = n < n_extrapolacao_min`.
- Retorna DataFrame com colunas (nessa ordem):
  `["tier_label", "metragem_min", "metragem_max", "n", "p10", "p50", "p90", "flag_extrapolacao", "versao_contrato"]`
  com exatamente 5 linhas na ordem dos tiers.
- `versao_contrato = VERSAO_CONTRATO` em todas as linhas.
- Tipos: `tier_label` str, `metragem_min` float64, `metragem_max` float64, `n` int64, `p10/p50/p90` float64, `flag_extrapolacao` bool, `versao_contrato` str.
- **Nota sobre `metragem_max` para `">=3000"`:** usar `float("inf")` — o Parquet/Arrow suporta `inf` em float64; o consumidor (VIAB-03) trata `inf` como "sem teto".

#### 1g. `materializar(df_tiers: pd.DataFrame, staging_dir: Path | str, analysis_dir: Path | str) -> tuple[Path, Path]`

```python
def materializar(
    df_tiers: pd.DataFrame,
    staging_dir: Path | str,
    analysis_dir: Path | str,
) -> tuple[Path, Path]:
```

- `staging_dir = Path(staging_dir)` / `analysis_dir = Path(analysis_dir)` (cria dirs se ausentes via `mkdir(parents=True, exist_ok=True)`).
- Escreve `staging_dir / "demanda_premissa_por_tier.parquet"` via `df_tiers.to_parquet(..., index=False)`.
- Gera `data/analysis/demanda_premissa_qualidade.md` — ver conteúdo no Passo 2.
- Retorna `(parquet_path, md_path)`.

#### 1h. `run(ultra_path: Path | str, eng_path: Path | str, staging_dir: Path | str, analysis_dir: Path | str) -> tuple[Path, Path]`

```python
def run(
    ultra_path: Path | str,
    eng_path: Path | str,
    staging_dir: Path | str,
    analysis_dir: Path | str,
) -> tuple[Path, Path]:
```

- Orquestra: `carregar_ultra` → `carregar_eng_corpo` → `combinar_bases` → `calcular_tiers` → `materializar`.
- Retorna `(parquet_path, md_path)` de `materializar`.
- É o ponto de entrada CLI/batch.

## Riscos técnicos

1. **`metragem_max = float("inf")` no Parquet:** PyArrow suporta `inf` em float64; nenhum risco.
   Se por alguma razão o leitor downstream rejeitar `inf`, o VIAB-03 pode usar `1e9` como sentinel —
   mas o Builder não deve antecipar isso (o VIAB-03 é o responsável pelo contrato de consumo).

2. **`openpyxl` ausente no ambiente de teste:** improvável (é dep do pyproject), mas o Builder deve
   confirmar com `python -c "import openpyxl"` antes de escrever o código.

3. **N real pode diferir do preview do BO (17/46/36/11/2):** o preview foi calculado com os dados
   reais mas sem executar o código novo. O Builder deve executar `run(...)` e comparar o `n` real
   com o preview. Se divergir, atualizar o relatório de qualidade com os valores reais (não
   hardcoded) — o template do md usa os valores lidos do df, não constantes.

4. **Coluna `Metragem M²` no xlsx Eng Corpo:** o cabeçalho contém `²` (caractere especial). Verificar
   que `pd.read_excel` lê corretamente no ambiente; caso haja problema de encoding, usar
   `engine="openpyxl"` explicitamente (já é o default, mas explicitado na dica).

5. **Tier `<1000` com N=17:** o preview indica N=17; na fixture sintética o Builder deve testar
   um tier com N=2 para cobrir o `flag_extrapolacao=True` sem depender do dado real.
