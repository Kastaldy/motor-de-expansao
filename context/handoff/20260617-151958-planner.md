### 1. `p_viavel(m2, break_even, base_calibracao_df, formato=None)`
Assinatura:
```python
def p_viavel(
    m2: float,
    break_even: float,
    base_calibracao_df: pd.DataFrame | None,
    formato: str | None = None,
    *,
    tolerancia: float = FAIXA_M2_TOLERANCIA,
    tolerancia_alargada: float = FAIXA_M2_TOLERANCIA_ALARGADA,
    n_min: int = N_MIN_COMPARAVEIS,
) -> float | None:
```
Lógica (espelha a janela de `faixa_alunos_por_densidade`, mas com filtro de formato ANTES do m²):
1. Se `base_calibracao_df is None or len(...) == 0` → **return None**.
2. Se `"alunos_por_m2" not in columns` → **return None**.
3. `df = base.copy()`; `df["__apm"] = pd.to_numeric(df["alunos_por_m2"], errors="coerce")`;
   filtrar `np.isfinite(__apm) & (__apm > 0)`. Se vazio → **return None**.
4. **Filtro de formato (D2), ANTES do m²:** se `formato is not None`, resolver a coluna de formato
   (primeira de `COL_FORMATO_CANDIDATAS` presente em `df.columns`). Se achou coluna:
   `df_fmt = df[df[col].astype(str).str.strip().str.casefold() == str(formato).strip().casefold()]`.
   Se `len(df_fmt) >= n_min` → usa `df_fmt`; senão → mantém `df` (fallback sem filtro de formato,
   silencioso). Se nenhuma coluna candidata existir → ignora o filtro (usa `df`).
   *(Comparação case-insensitive e com strip para robustez.)*
5. **Janela de m²** (sobre o df pós-formato), idêntica em ESPÍRITO ao engine existente:
   - usar coluna `metragem` (numérica) se existir; senão a janela é a base inteira.
   - estreita `m2*(1-tol) .. m2*(1+tol)`; se `len < n_min` → alargada `(1±tol_alargada)`;
     se ainda `len < n_min` → base inteira (o df pós-formato/limpeza).
   - Se a janela final ficar vazia → **return None**.
6. Para cada comparável da janela: `alunos_comparavel = __apm * m2`.
7. **Retornar** `float(fração dos comparáveis onde alunos_comparavel > break_even)`, em [0.0, 1.0].
   - Implementar vetorizado: `frac = float((apm_arr * m2 > break_even).mean())`.
   - **GUARDRAIL: a função NÃO recebe lat/lng** (nem os usa).

Notas de borda:
- `break_even` pode ser `float("inf")` (vem de `alunos_minimos_viaveis` quando inviável) → todos os
  comparáveis falham `> inf` → fração 0.0 (correto, não None). Não tratar como caso especial.
- Comparação **estrita `>`** (supera o break-even). Documentar.

### 2. `classe_risco(p_viavel)`
```python
def classe_risco(p_viavel: float | None) -> str:
```
- `p_viavel is None` → `"INDISPONIVEL"`.
- `p_viavel >= CUTOFF_GO` (0.70) → `"GO"`.
- `p_viavel >= CUTOFF_ATENCAO` (0.40) → `"ATENCAO"`.
- senão → `"NAO"`.
- (Cutoffs do estudo §7: GO P≥70%, ATENÇÃO 40–70%, NÃO <40%.)

### 3. `ranking_oportunidades(lista_imoveis)` — DORMENTE
```python
def ranking_oportunidades(lista_imoveis: list[dict]) -> list[dict]:
```
- Recebe lista de dicts com pelo menos `{"p_viavel": float|None, "break_even": float}` e `id` opcional.
- **Ordena por `p_viavel` DESC**; **None vai para o FIM**; desempate por `break_even` ASC.
- Implementação sugerida (estável, sem mutar a entrada):
  `key = lambda im: (im.get("p_viavel") is None, -(im.get("p_viavel") or 0.0), im.get("break_even", float("inf")))`
  e `return sorted(lista_imoveis, key=key)`.
  - O 1º elemento da tupla (`is None`) empurra None para o fim independentemente do resto.
  - O `-(p or 0.0)` dá DESC para os não-None (None usa 0.0, mas já foi para o fim pela flag).
- **DORMENTE:** a função EXISTE mas `RANKING_ATIVO = False` no módulo e ela NÃO é chamada por
  nenhum render. O Builder **NÃO** referencia/chama `ranking_oportunidades` em `pages.py` nem em
  qualquer arquivo de `dashboard/`.
