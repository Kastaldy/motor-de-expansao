## Verificação técnica realizada (R3 resolvido — NÃO assumido)
- `fpdf` instalado = **2.8.7**. API confirmada por inspeção (`inspect.signature`) e smoke real:
  - Rotação: `with pdf.rotation(angle: float, x: float | None, y: float | None):` (context-manager; afeta só o render dentro do bloco; estabelece graphics state local).
  - Transparência: `with pdf.local_context(fill_opacity=<0..1>):` — chave válida é **`fill_opacity`** (e opcional `stroke_opacity`). **`text_opacity` NÃO existe nesta versão (levanta `ValueError: Unsupported setting`)** — NÃO usar.
  - Smoke com `set_compression(False)` confirmou: o texto da marca d'água aparece nos bytes crus (`b"Ultra Academia | Analista Teste" in bytes` = True) e `fill_opacity` gera estado de alpha real (`/ca` presente).
  - Ordem recomendada: `with pdf.local_context(fill_opacity=...):` por FORA, `with pdf.rotation(45, x, y):` por DENTRO, e `pdf.text(x, y, texto)` no miolo (usar `pdf.text`, não `cell`, para posicionar pelo baseline sem depender de margens).

## Plano técnico
Arquivo único de produção: `src/motor_expansao/dashboard/censo_report.py`. Propagação mínima em `pages.py`. Testes em `tests/unit/test_relatorio_pontual_censitario_export.py`.

1. **Constantes da marca d'água** (topo do módulo, junto à paleta, ~linhas 57-66): adicionar

   - `_WATERMARK_RGB = (120, 120, 120)` (cinza)
   - `_WATERMARK_ALPHA = 0.16` (translúcido — visível sem obstruir leitura; ajustável)
   - `_WATERMARK_ANGLE = 45.0`
   - `_WATERMARK_FONT_PT = 60`
   Manter ASCII-safe (passa por `_ascii`).

2. **Função privada `_watermark_text(solicitante: str | None) -> str`** (logo após `_ascii`, ~linha 131):
   - `solicitante is None` ou string vazia após `.strip()` → retorna `_WATERMARK_BASE`.
   - Caso contrário → `f"{_WATERMARK_BASE} | {solicitante.strip()}"`.
   - Aplicar `_ascii(...)` no retorno (core font Helvetica latin-1).

3. **Função privada `_draw_watermark(pdf: _UltraPDF, text: str) -> None`** (logo antes de `_cover_page`, ~linha 240, ao lado dos outros helpers de desenho):
   - Define fonte: `pdf.set_font("Helvetica", "B", _WATERMARK_FONT_PT)`; `pdf.set_text_color(*_WATERMARK_RGB)`.
   - Centro da página: `cx, cy = _PAGE_W / 2.0, _PAGE_H / 2.0`.
   - Calcular x de início para centralizar horizontalmente o texto: `w = pdf.get_string_width(text)`; `x0 = cx - w / 2.0`; `y0 = cy` (baseline aproximado no centro).
   - Render:
     ```
     with pdf.local_context(fill_opacity=_WATERMARK_ALPHA):
         with pdf.rotation(_WATERMARK_ANGLE, x=cx, y=cy):
             pdf.text(x0, y0, text)
     ```
   - Usar `pdf.text(...)` (posiciona pelo baseline, imune a `set_margins(0,0,0)` e auto_page_break OFF). NÃO usar `cell`/`multi_cell` aqui.
   - Função é READ-ONLY de estado lógico (rotation/local_context restauram o graphics state ao sair; `get_x/get_y` não são afetados — confirmado na doc da API).

4. **Aplicar a marca d'água em cada página DEPOIS do conteúdo e ANTES do `output()`** (R2). Em `gerar_pdf_relatorio_pontual_censitario` (~linha 533-543), APÓS a última página (`_credit_page`) e ANTES de `output = pdf.output()`, inserir um ÚNICO loop sobre as páginas já compostas — este é o PONTO DE VARIAÇÃO isolado para D2:
