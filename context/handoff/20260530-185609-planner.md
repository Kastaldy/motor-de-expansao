## Pontos de atenção

- **Skyfit xlsx**: header real na **linha 4** → `header=3`. Não usar staging (0 linhas) nem CSV de 482 (super-set).
- **Cardinalidades que não batem**: EngCorpo 63 staging vs 62 planilha (1 a mais no staging → vira não-casado/registrar);
  Skyfit ~347 planilha vs 0 staging vs 482 CSV (usar só planilha). Documentar diffs na auditoria, não falhar o build.
- **5/54 Ultra sem hex** → `hex_resolvido=False`; tentar derivar de lat/lng antes de desistir.
- **Score de domínio**: só 500 hexes → nulo + flag no restante; é esperado e não é erro.
- **PII**: nomes/endereços nunca em logs, handoff ou no relatório de auditoria (só agregados). O parquet pode conter
  `nome_unidade` (uso interno), mas é gitignored.
- **Encoding/sep**: `Ultra.csv` latin-1 sep=";" skiprows=1 (só fallback); qualquer CSV gerado pelo projeto sep=";" utf-8-sig.
- **h3**: import opcional (pode estar ausente) → degradar para `hex_resolvido=False`, não quebrar.
- **READ-ONLY**: nenhuma escrita em parquet/CSV oficial do M1; nenhum recálculo de score/peso/carteira/plano.
- **Chave de join (VERIFICADO)**: as três fontes de score (`brasil_priorizados`, `hexagonos_mercado_mapeado`,
  `plano_expansao_dominio`) usam `hex_id`. Não existe `hexagono_id`. O parquet Ultra tem `hex_id_res7` e `hex_id`.
- **`cod_municipio` é string** em todas as fontes — não converter para int (perderia zeros à esquerda).
- **Ultra parquet não tem** `cod_municipio`/`score_setor_2022_calibrado`/`score_oportunidade_residual`/`score_dominio_hibrido`:
  todos vêm via join por `hex_id` (não assumir embutidos).

## Riscos e mitigação

- **Match por nome impreciso** (homônimos, grafias) → exigir `cod_municipio` no match quando disponível;
  match exato determinístico; não-casados auditados, nunca silenciosos.
- **hex não resolvido para Skyfit** (sem coords) → maioria sem 4 scores; aceitar como cobertura parcial + flags;
  decisão de geocoding fica fora (sem API ao vivo).
- **Fontes gitignored ausentes no CI** → toda lógica testada por fixtures; `main()` só lê fontes reais em runtime local.
- **PII vazando** → relatório de auditoria só com agregados; logs sem nome/endereço.
- **Quebra de read-only** → nenhuma função escreve em paths do M1; teste/QA confere git status.
- **Dependência xlsx (openpyxl)** → confirmar no ambiente; se ausente, Builder adiciona a dep de leitura (não de dados).
