## Causa raiz da falha de CI
O CI completo (habilitado por BLK-OPS-02) rodou no PR #1 e FALHOU com **exit code 2 — erro de COLETA do pytest**, não de teste:
```
ModuleNotFoundError: No module named 'psutil'
```
em 3 módulos de teste (`test_fase_a_nacional_completo.py`, `test_fase_a_piloto_expandido.py`, `test_validar_fase_a_censo2022.py`) que importam transitivamente `jobs/pipelines/validar_fase_a_censo2022.py` (linha 17: `import psutil`, nível de módulo). `psutil` estava instalado no ambiente local do dev (por isso o pytest local deu 532 passed e mascarou a lacuna), mas **NÃO estava declarado em `pyproject.toml`** — `pip install -e ".[dev]"` no runner limpo não o instala e a coleta aborta. `psutil` também é importado por `scripts/profile_dashboard.py`. É dependência de runtime de produção (pipeline Fase A), não só de teste.

## O que foi feito
- `pyproject.toml`: adicionado **`"psutil>=5.9.0"`** às `dependencies` CORE (seção "# Utilitarios", após `click>=8.1.0`). NÃO no extra `[dev]`, pois é importado por código de produção do pipeline. Piso `>=5.9.0` compatível com o instalado localmente (7.1.1) e com o estilo `>=` do arquivo.
