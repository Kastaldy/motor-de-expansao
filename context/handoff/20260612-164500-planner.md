### Passo 2 — GAP no container do seletor (inserir antes do bloco 304-314)

**Arquivo:** `src/motor_expansao/dashboard/pages.py`
**Localização:** inserir uma nova regra CSS **imediatamente antes** do bloco dos botões inativos (linha 304), ainda dentro do `<style>` de `inject_styles()`.

**Seletor escolhido:** `div[data-testid="stSegmentedControl"]`
- É o seletor raiz já presente no bloco (304-314 usa `[data-testid="stSegmentedControl"] button`); adicionar a versão `div[...]` sem o `button` é extensão natural e robusta.
- O `st.segmented_control` renderiza um `div[data-testid="stSegmentedControl"]` contendo um `div` flex interno com os botões. Adicionar `display: flex` + `gap` ao container pode não casar diretamente se o flex está no filho `> div`. Portanto, adicionar também `> div` como fallback seguro.

**Regra a inserir:**
```css
div[data-testid="stSegmentedControl"],
div[data-testid="stSegmentedControl"] > div {
    display: flex;
    gap: 8px;
}
```

**Valor de gap:** `8px` (≈ 0.5rem) — discreto, perceptível, compatível com o layout.

**Risco de não-casamento:** se o seletor não casar na versão do Streamlit em produção, o gap simplesmente não aplica (sem regressão visual, sem erro). O teste só verifica presença de strings no CSS, não renderização.

### Passo 3 — Botões INATIVOS: slate mais claro, distinto dos cartões (pages.py:304-314)

**Arquivo:** `src/motor_expansao/dashboard/pages.py`
**Localização:** regra base dos botões inativos, linhas 304-314.


**Mudança exata:**
- `background: rgba(18,23,42,0.92)` → `background: rgba(30,38,65,0.88)`
  - Cartões usam `rgba(18,23,42,0.96)` (escuro navy profundo).
  - `rgba(30,38,65,0.88)` é um slate azulado mais claro (R+12, G+15, B+23 vs cartões) — perceptivelmente diferente em tema dark.
- `border: 1px solid {COLORS["border"]}` → `border: 1px solid rgba(25,183,255,0.30)`
  - Borda ciano suave (30% opacidade) sinaliza que é o seletor de navegação, não um cartão de dados.
- `color: {COLORS["muted"]}` → manter (texto acinzentado; legível sobre slate claro).
- `border-radius: 10px`, `font-size: 1rem`, `font-weight: 600`, `padding: 0.5rem 1.15rem` → manter tudo.

**Bloco resultante:**
```css
[data-testid="stSegmentedControl"] button,
div[role="radiogroup"] [data-baseweb="button"],
[data-baseweb="button-group"] button {
    background: rgba(30, 38, 65, 0.88);
    color: {COLORS["muted"]};
    border: 1px solid rgba(25, 183, 255, 0.30);
    border-radius: 10px;
    font-size: 1rem;
    font-weight: 600;
    padding: 0.5rem 1.15rem;
}
```
