**Dataclass de resultado**:
```python
@dataclass
class HuffModel:
    beta: float                       # expoente de decaimento calibrado (LOO-agregado)
    beta_ic95: tuple[float, float]    # IC95 bootstrap de β
    beta_indistinguivel_de_zero: bool # True se IC de β toca BETA_BOUNDS[0] OU corr LOO ~0
    corr_loo_share_alunos: float      # Spearman(share_loo, alunos_reais) — métrica honesta
    corr_loo_ic95: tuple[float, float]
    auc_loo_viavel: float             # AUC share_loo discrimina viável(>=2000) vs inviável
    auc_loo_ic95: tuple[float, float]

    n_treinamento: int
    n_outliers_removidos: int
    flag_extrapolacao_padrao: bool    # n < N_MIN_CALIBRACAO
```

**Funções (assinaturas exatas + corpo resumido)**:

1. `_haversine_vec(lat0: float, lng0: float, lats: np.ndarray, lngs: np.ndarray) -> np.ndarray`
   - Vetoriza haversine de 1 ponto a N pontos. Copiar o corpo numpy de `_conc_por_km2`
     (base_multirede linhas 341-348), retornando o array `dist` em km. Guard: arrays vazios → `np.array([])`.

2. `_carregar_concorrentes(conc_path: Path = CONCORRENTES_PATH, *, conc_df: pd.DataFrame | None = None) -> tuple[np.ndarray, np.ndarray]`
   - Lê parquet (ou usa `conc_df` injetado em teste — IGNORA path quando passado).
   - Filtra `flag_coord_valida` quando a coluna existe; coage `lat`/`lng`; descarta NaN.
   - Retorna `(conc_lat, conc_lng)` float arrays. **Nunca retorna/persiste `nome_unidade`.**

3. `share_huff(dist_propria_km: float, dist_concorrentes_km: np.ndarray, beta: float, *, atr_propria: float = ATRATIVIDADE_PROPRIA, atr_concorrente: float = ATRATIVIDADE_CONCORRENTE) -> float`
   - Implementa `share_i = (atr_propria / d_i^β) / (atr_propria/d_i^β + Σ_j atr_conc/d_j^β)`.
   - `dist_propria_km` = distância "típica" do morador à própria unidade ≈ `DIST_BASE_KM`
     (proxy de catchment; a unidade-alvo é o centro do seu catchment).
   - Clampa distâncias a `>= DIST_MIN_KM`. Denominador = numerador + soma concorrentes.
   - Concorrentes vazios → share = 1.0 (monopólio local). Retorna float em [0,1].
   - **PURA** — sem alvo, sem fallback `where(isnan, y, ...)`. Esta é a função-núcleo.

4. `_share_loo_para_unidade(i: int, lats: np.ndarray, lngs: np.ndarray, conc_lat, conc_lng, beta: float) -> float`
   - Para a unidade i: dist própria = `DIST_BASE_KM`; concorrentes = TODOS os de
     `concorrentes_mapeados` (OSM, externos — NÃO são as outras unidades-alvo) DENTRO de um
     raio de catchment (usar `DIST_BASE_KM * 2` como janela, ou todos; ver D5) + **canibalização**:
     as OUTRAS unidades-alvo da MESMA `marca` próximas entram como concorrentes adicionais
     (share próprio dividido). A unidade i NUNCA entra como seu próprio concorrente (anti-circular).
   - Retorna `share_huff(...)`. NÃO usa `alunos_reais` em nenhum ponto.

5. `_calibrar_beta_loo(base, conc_lat, conc_lng, *, beta_bounds=BETA_BOUNDS) -> tuple[float, np.ndarray]`
   - **LOO honesto**: para cada unidade-alvo deixada de fora, β é re-otimizado nas DEMAIS
     unidades (maximizando |Spearman(share, alunos)| das demais, via `minimize_scalar`
     com `bounds`, `method="bounded"`, objetivo = `-abs(spearman)`), e então aplicado SÓ
     à unidade deixada de fora para gerar `share_loo[i]`. Retorna `(beta_mediano_loo, share_loo)`.
   - **Anti-vazamento**: o alvo (alunos) da unidade i NUNCA entra na otimização do β usado nela.
   - Guard: grupo de treino com <3 unidades válidas → `share_loo[i]=nan`.
   - Spearman via `scipy.stats.spearmanr` (importar lazy dentro da função) OU ranking manual
     numpy. Preferir `scipy.stats.spearmanr` (scipy já é dependência).

6. `_ic_bootstrap(valores: np.ndarray, *, rng, n=N_BOOTSTRAP) -> tuple[float,float]`
   - IC95 percentil (2.5/97.5) por bootstrap de uma amostra de valores finitos. Reusável
     para β e para a correlação. Padrão do `_ic_bootstrap_auc` de residual_discriminacao,
     simplificado (sem classe única).

7. `calibrar_huff(base: pd.DataFrame, *, conc_path: Path = CONCORRENTES_PATH, conc_df: pd.DataFrame | None = None, rng_seed: int = SEED) -> HuffModel`
   - Orquestra: valida colunas obrigatórias `{lat,lng,alunos_reais,marca}`; remove linhas
     sem coord/alunos (conta `n_outliers_removidos`); levanta `ValueError` se N < 5 (igual aderencia).
   - Carrega concorrentes; chama `_calibrar_beta_loo`; computa:
     - `corr_loo_share_alunos` = Spearman(share_loo, alunos) sobre finitos;
     - `auc_loo_viavel` = AUC(flag_viavel = alunos>=PISO_VIABILIDADE_ALUNOS, share_loo) com guard de classe única → nan;
     - `baseline_corr` = Spearman(-log1p(n_conc_no_raio), alunos) — baseline SEM β (proxy grosseiro do residual);
     - IC95 de β e de corr via bootstrap das unidades (reamostra índices, recomputa share_loo já calculado? NÃO — bootstrap sobre o vetor de pares (share_loo, alunos): reamostra pares e recomputa Spearman; para β, bootstrap sobre os betas-por-fold do LOO).
   - `beta_indistinguivel_de_zero` = True se `corr_loo_ic95` cruza 0 OU `beta_ic95` colado em `BETA_BOUNDS[0]`.
   - `veredito` = "GO" se `abs(corr_loo_share_alunos) >= CORR_GO_MIN` E `corr_loo_ic95` NÃO cruza 0; senão "NO-GO".
   - Monta `nota_honesta` (PT, sem PII) com β, ICs, vereditos, confounds; loga via `_logger.info` (só números).
   - Retorna `HuffModel`.

8. `relatorio_huff(modelo: HuffModel) -> str`
   - String multilinha legível (PT, sem PII), padrão `relatorio_aderencia`. Inclui a frase-guardrail
     anti-predição literal (ver D7) e confounds.

9. `escrever_relatorio_huff(modelo: HuffModel, *, path: Path = Path("data/analysis/huff_calibracao.md")) -> None`
   - Materializa markdown (gitignored). Seções `## 1. ... ## 5.` no padrão dos relatórios DIM:
     1. Setup/N; 2. Calibração de β (grade + LOO + IC); 3. Validação honesta (corr/AUC LOO vs baseline + IC);
     4. Veredito GO/NO-GO de β; 5. Confounds + frase-guardrail. `path.parent.mkdir(parents=True, exist_ok=True)`.
   - **Nunca lista unidades nominalmente; nunca escreve `nome_unidade`.**

10. `executar(*, base_path=SAIDA_BASE, conc_path=CONCORRENTES_PATH, relatorio_path=Path("data/analysis/huff_calibracao.md")) -> HuffModel`
    - Caminho real (NÃO chamado em teste): `base = pd.read_parquet(base_path)`; `assert_sem_pii(base)`;
      `modelo = calibrar_huff(base, conc_path=conc_path)`; `escrever_relatorio_huff(modelo, path=relatorio_path)`; retorna modelo.

## Decisões técnicas

- **D1 — β calibrado por LOO honesto, não in-sample.** Para cada unidade deixada de fora, β é
  otimizado nas demais (objetivo = maximizar |Spearman(share, alunos)|) e aplicado só à unidade-alvo.
  O β reportado é o agregado (mediana) dos folds + IC bootstrap dos betas-por-fold. Justificativa:
  espelha o padrão `aderencia._r2_loo_para_alpha` (LOO sem vazamento) e a disciplina DEC-008.

- **D2 — Métrica honesta = correlação/AUC de RANKING, não R².** O alvo é "β distinguível de zero / share
  discrimina", NÃO prever alunos absolutos (DIM-01R deu NO-GO p/ absolutos). Spearman(share_loo, alunos)
  + AUC(viável, share_loo), ambos com IC bootstrap, vs baseline `-log1p(n_conc_no_raio)` (proxy grosseiro
  do residual atual). É a comparação "Huff geométrico vs proxy sem distância" pedida pelo BO.

- **D3 — Atratividade = 1.0 por concorrente (sem capacidade).** `concorrentes_mapeados` não tem coluna de
  capacidade; inventar capacidade por rede seria não-validável. `metragem` da própria unidade é esparsa
  (skyfit toda NaN) → NÃO usar como atratividade (introduziria viés por marca/cobertura). β é o ÚNICO
  parâmetro livre. Documentado no relatório como simplificação consciente.

- **D4 — `share_huff` é PURA e geométrica.** Não recebe nem usa `alunos_reais`. PROIBIDO qualquer
  `pot = where(isnan(pot), y, pot)` ou variante. O vazamento do spike fica estruturalmente impossível
  porque a função-núcleo não tem acesso ao alvo. Teste 8 trava isso.

- **D5 — Distância própria = `DIST_BASE_KM=1.66`** (raio mediano BLK-DIM-07). A unidade-alvo é o centro do
  próprio catchment; usamos uma distância típica morador→unidade como referência. Concorrentes entram com
  sua distância real (haversine) à unidade-alvo. NÃO derivar distância de nº de alunos (anti-circular).

- **D6 — Canibalização própria.** Outras unidades da MESMA `marca` entram como concorrentes no denominador
  (share dividido entre rede própria), conforme spec §4 "descontar share captado por outras unidades próprias".
  A unidade-alvo nunca é seu próprio concorrente.

- **D7 — Frase-guardrail anti-predição literal** (constante de módulo, testada por substring, NÃO alterar texto):
  `"Saida como beta/share de ranking; NUNCA previsao pontual de N alunos por hex."`

- **D8 — IC por bootstrap percentil** (2.5/97.5), seed fixo `SEED=42`, determinístico. Reusa padrão de
  `_ic_bootstrap_auc` do DIM-08.

- **D9 — Gate GO/NO-GO explícito e simétrico.** GO se `abs(corr_loo) >= CORR_GO_MIN=0.15` E IC de corr não
  cruza 0. Caso contrário NO-GO (resultado VÁLIDO — documenta que distância a concorrentes não explica share).

- **D10 — Sem dependências novas.** numpy, pandas, scipy, sklearn já no projeto. `scipy.optimize.minimize_scalar`
  e `scipy.stats.spearmanr` confirmados disponíveis.
