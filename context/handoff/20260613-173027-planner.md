## DESCOBERTA QUE SIMPLIFICA O BLOCO (revoga o medo de "batch geométrico lento")

cruzamento geométrico por unidade e **JÁ DEVOLVE todas as 4 features** que precisamos, mais o
frame de setores intersectados:

- `result["densidade_pop_raio_hab_km2"]` → **feature `densidade_pop_catchment_hab_km2`** (direto).
- `result["setores_intersectados"]` → DataFrame com colunas `pop_total_setor_2022`,

  `renda_per_capita_setor_2022_calibrada`, `densidade_pop_setor_hab_km2`. A partir dele derivamos
  `renda_responsavel_media_catchment` (média ponderada por `pop_total_setor_2022`) e
  `domicilios_captacao` (ver nota abaixo).
- `analisar_ponto_censitario_setores(..., competitors_df=df_conc)` retorna `result["n_concorrentes"]`
  = concorrentes no raio de 1.5 km → **feature `n_concorrentes_raio_1_5km`** (NÃO precisa de
  Haversine separado; o helper já filtra por raio via `_points_in_radius`).

**Logo: as 4 features saem de UMA passada por unidade, reusando exatamente o mesmo loop e cache-por-UF
que `catchment_batch.calcular_catchment_batch` já implementa.** O Builder deve modelar
`derivar_features_censo` espelhando esse loop (cache `dict[str, DataFrame]` por UF). 54 unidades ×
~poucos setores no bbox = rápido. NÃO é o cruzamento de 468k setores que o BO temia.

Reimplementar um LOO-CV Ridge multi-feature dentro de `features_exogenas.py`. NÃO importar

`log(pagantes) = b0 + Σ b_i * x_i`, onde `x_i ∈ {log(pop), log(renda), n_conc, log1p(densidade), log(renda_resp)}`
conforme o feature_set. Features de contagem/densidade entram como definido em D3 (ver abaixo).

```python
def _loo_ridge_multifeature(
    X: np.ndarray, y: np.ndarray, alpha_grid: tuple[float, ...] = ALPHA_GRID,
) -> dict:
    """LOO-CV Ridge multi-feature, alvo y=log(pagantes). Seleciona alpha por MENOR rmse_loo_log.

    Espelha aderencia._r2_loo_para_alpha + a varredura de calibrar_aderencia, mas para X de
    qualquer largura. Retorna dict com:
      alpha_selecionado, r2_loo_log, rmse_loo_log, r2_loo_pagantes, rmse_loo_pagantes,
      r2_insample_log, coef (np.ndarray), intercepto_log.
    Sem scaler (features ja em escala log/contagem comparavel). Pura, testavel offline.
    """
    # Logica de referencia (copiar fielmente de aderencia.py L135-153 e L287-322):
    #  for alpha in grid: LeaveOneOut -> Ridge(alpha).fit(train).predict(test) -> y_pred_loo
    #    r2_loo = 1 - ss_res_loo/ss_tot ; rmse_loo = sqrt(mean((y_pred-y)^2))
    #    escolher menor rmse_loo
    #  back-transform exp(y_pred_loo) -> r2_loo_pagantes / rmse_loo_pagantes
    #  modelo final Ridge(alpha*).fit(X,y) -> coef, intercept, r2_insample_log
```
