#### Detalhes de cada gráfico

**(a) `gerar_grafico_cobertura_huff`**
- Fonte: `df_mercado` (hexagonos_mercado_mapeado; passado com coluna `share_captura_huff` e `uf`).
- Cálculo: `share < 1.0` por hex → agrupa por `uf` → % de hexes "competitivos" por UF.
- Gráfico: barras verticais ordenadas por % decrescente, eixo Y em %, título descritivo.
- Nota no gráfico: "Estado atual — base densa ATR-01 não materializada".
- Arquivo: `cobertura_huff.png`.

**(b) `gerar_grafico_gate_por_uf`**
- Fonte: `df_join` (join antes do gate, com coluna `uf`) e `df_pos_gate` (após gate).
- Cálculo: por UF, conta hexes aprovados e reprovados; mostra só UFs com ≥ 5 hexes no join.
- Gráfico: barras empilhadas (verde=aprovado, vermelho=reprovado), UF no eixo X.
- Arquivo: `gate_por_uf.png`.

**(c) `gerar_grafico_distribuicoes_eixos`**
- Fonte: `df_norm` (após `normalizar_eixos`), que tem `eixo_sociodemo_norm`, `eixo_mercado_norm`,
  `eixo_disputa_norm`.
- Gráfico: figura com 3 subplots (`1×3`), histograma de 20 bins para cada eixo normalizado (0–100),
  linha vertical na mediana.
- Arquivo: `distribuicoes_eixos.png`.

**(d) `gerar_grafico_quadrantes`**
- Fonte: `df_pos_gate` (com `score_oportunidade_residual` e `share_captura_huff`).
- Cálculo:
  - Eixo X: `score_oportunidade_residual`; corte na mediana.
  - Eixo Y: `1 - share_captura_huff` (disputa); corte na mediana.
  - 4 quadrantes:
    - Q1 (alto residual, alta disputa): "Mercado grande e disputado"
    - Q2 (alto residual, baixa disputa): "Nicho defensável (oportunidade prime)"
    - Q3 (baixo residual, alta disputa): "Espaço saturado"
    - Q4 (baixo residual, baixa disputa): "Mercado maduro"
  - Anotar contagem em cada quadrante.
- Gráfico: scatter (pontos semi-transparentes alpha=0.3, tamanho pequeno) + linhas de corte (medianas)
  + texto anotado nos 4 quadrantes.
- Arquivo: `quadrantes_residual_disputa.png`.

**(e) `gerar_grafico_r2_modelos`**
- Fonte: `result: EstruturaFunilResult` (tem `result.modelos`, cada `ModeloOOF` tem `.r2_oof`,
  `.ic95_r2`, `.nome`).
- Ordem de exibição: `baseline`, `sociodemo`, `mercado`, `disputa`, `censitario`, `composto`,
  `pesos_iguais`.
- Gráfico: barras horizontais, IC95 como barras de erro (`xerr`), linha vertical em 0, cor
  diferenciada para `composto` (azul escuro), `baseline` (cinza).
- Título inclui o veredito: f"Veredito: {result.veredito}".
- Modelos ausentes (ex: censitário se não houver dados) são omitidos silenciosamente.
- Arquivo: `r2_modelos.png`.

**(f) `gerar_grafico_correlacoes`**
- Fonte: `result.correlacoes_cruzadas` (3 pares: `mercado_x_disputa`, `sociodemo_x_mercado`,
  `sociodemo_x_disputa`) + construir matriz 3×3.
- Construção da matriz 3×3 simétrica para o heatmap:
  - Diagonal = 1.0
  - Off-diagonal de `correlacoes_cruzadas`
  - Labels: `["sociodemo", "mercado", "disputa"]`
- Gráfico: `imshow` com colormap `RdBu_r` (centrado em 0), anotações de valor em cada célula,
  colorbar.
- Arquivo: `correlacoes_eixos.png`.

#### `gerar_relatorio_markdown`
- Recebe `result` e `paths_png: dict[str, Path]` (chave = nome curto, valor = Path do PNG).
- Emite seções: cabeçalho, veredito, tabela de modelos (R2_oof + IC95), quadrantes (contagens),
  caminhos dos PNGs, confounds obrigatórios (copiados da `result.nota_honesta`).
- Chama `_assert_sem_pii_no_relatorio` (igual ao `estrutura_funil.py`) antes de gravar.
- Arquivo: `relatorio_viz.md`.

#### `executar` (pragma: no cover)
```python
def executar(mkt_path: Path, dem_path: Path, *, out_dir: Path) -> None:  # pragma: no cover
    """Orquestrador de disco: join, harness ATR-03, 6 PNGs + markdown."""
    from .estrutura_funil import (
        _carregar_join,  # função interna — OK pois é mesmo pacote
        aplicar_gate_atratividade,
        avaliar_estrutura_funil,
        normalizar_eixos,
    )
    import pyarrow.parquet as pq

    # carrega só as colunas necessárias do mercado (evitar 139 colunas)
    cols_mkt = [
        "hex_id", "score_priorizacao", "score_oportunidade_residual", "share_captura_huff",
        "score_setor_2022_calibrado", "renda_per_capita", "uf", "populacao_corte_hex",
        "confianca_geografica", "pop_total_setor_2022", "pop_total", "populacao_proxy",
        "qualidade_join_uf", "flag_censo_disponivel",
    ]
    disponiveis = set(pq.ParquetFile(mkt_path).schema.names)
    df_mkt = pd.read_parquet(mkt_path, columns=[c for c in cols_mkt if c in disponiveis])
    df_dem = pd.read_parquet(dem_path, columns=["hex_id", "membros"])
    df_join = df_dem.merge(df_mkt, on="hex_id", how="inner")

    df_pos, _ = aplicar_gate_atratividade(df_join)
    df_norm = normalizar_eixos(df_pos)
    result = avaliar_estrutura_funil(df_join)  # inclui gate + normalização internamente

    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)

    paths_png: dict[str, Path] = {}
    paths_png["cobertura_huff"] = gerar_grafico_cobertura_huff(df_mkt, out_dir=out_dir)
    paths_png["gate_por_uf"] = gerar_grafico_gate_por_uf(df_join, df_pos, out_dir=out_dir)
    paths_png["distribuicoes"] = gerar_grafico_distribuicoes_eixos(df_norm, out_dir=out_dir)
    paths_png["quadrantes"] = gerar_grafico_quadrantes(df_pos, out_dir=out_dir)
    paths_png["r2_modelos"] = gerar_grafico_r2_modelos(result, out_dir=out_dir)
    paths_png["correlacoes"] = gerar_grafico_correlacoes(result, out_dir=out_dir)
    gerar_relatorio_markdown(result, paths_png, out_dir=out_dir)
```

**Nota:** `_carregar_join` de `estrutura_funil.py` é privada mas está no mesmo pacote — OK
importar. Alternativamente, reescrever o load inline no `executar` para não depender de função
privada. Preferir a abordagem inline para não acoplar a privados.

#### Boas práticas de estilo matplotlib no módulo

- Fechar cada figura após salvar: `plt.close(fig)` — evita acúmulo de memória.
- Usar `fig, ax = plt.subplots(...)` — não usar pyplot global.
- `fig.tight_layout()` antes de `fig.savefig(...)`.
- DPI de saída: `dpi=120` (boa qualidade sem arquivo enorme).
- Encoding UTF-8 para labels em PT: labels simples ASCII (sem acentos em labels de eixo;
  usar no título/anotações apenas se necessário — matplotlib pode ter problemas com caracteres
  especiais dependendo da instalação de fontes; preferir ASCII ou usar `usetex=False`).
