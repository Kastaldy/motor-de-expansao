("Título (Município/UF) + Faixa M1 + Score do modo ativo + Score censitário + Habitantes + Renda per

**Título conta como 1 dos 7** ⇒ o template final é `<b>{tooltip_title}</b>` + `tooltip_line_1..6` (6
campos de conteúdo, 7 linhas renderizadas no total). Isso diverge da convenção informal usada nos
comentários existentes do código ("_shared_map_tooltip, hoje 14 linhas" = 14 `tooltip_line_*`, título
à parte) — sinalizo a divergência aqui para que a validação visual humana pós-QA (já prevista no
`current_task.md`) confirme; se Felipe quiser título FORA da contagem, o ajuste é trivial (voltar o
template para `tooltip_line_1..7`, mesma estrutura de código, só mais uma linha).
