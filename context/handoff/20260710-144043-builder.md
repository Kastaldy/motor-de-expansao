## Problemas encontrados
- `pytest -n auto` (xdist) quebra com `INTERNALERROR> EOFError: couldn't load message header`
  neste ambiente (Windows, Python 3.14) — falha de infraestrutura do worker do xdist, não
  relacionada ao código alterado. Contornado rodando a suíte serial (`pytest -q` sem `-n auto`),
  que passou integralmente. Sinalizar ao QA para o mesmo contorno se o mesmo erro ocorrer lá.
- 3 erros de `mypy` de narrowing (`float | None` passado a `float()` após `pd.isna(value)`, que
  não estreita o tipo para o mypy) nos 3 helpers de formatação novos — corrigidos adicionando
  `value is None or` antes do `pd.isna(value)` em cada guarda.
- Testes iniciais escritos para o lookup usavam geometria com ponto exatamente sobre a fronteira
  compartilhada entre 2 setores (ambíguo por design — caso de tie-break), o que fazia o teste
  "dentro da malha" cair no cenário de tie-break em vez do cenário simples pretendido; corrigido
  ajustando a geometria de teste para o setor A cobrir o ponto por completo e o setor B ficar
  fora do fronteira compartilhada (o tie-break em si segue coberto implicitamente pelo próprio
  código, mas não tem um teste dedicado de "2 setores empatados" — nenhum teste explícito desse
  cenário raro foi pedido pelo plano além do já cumprido).
