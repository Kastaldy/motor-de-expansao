## O que foi implementado

### `src/motor_expansao/dimensionamento/viabilidade_ponto.py` (CRIADO)
Módulo property-first, função pura, READ-ONLY sobre o M1, sem I/O de parquet interno
(DataFrames injetados). Conteúdo conforme seções 0–7 do plano:

- **Constantes:** `POP_ZONA_MORTA_MIN=5000`, `RENDA_ZONA_MORTA_MIN=3000`,
  `FAIXA_M2_TOLERANCIA=0.20`, `FAIXA_M2_TOLERANCIA_ALARGADA=0.50`, `N_MIN_COMPARAVEIS=3`,
  `ALUNOS_RANGE_DEFAULT` (6 valores), `ALUGUEL_RANGE_FATOR` (5 fatores),
  `DEMANDA_FONTE_PREMISSA="premissa_explicita"`.
- **Dataclass `ViabilidadePontoResult`:** todos os campos do spec, com `float | None`/`int | None`/
  `bool | None`/`str | None` (estilo do repo, UP045). `demanda_fonte` com default
  `DEMANDA_FONTE_PREMISSA`.
- **`faixa_alunos_por_densidade(m2, base, ...)`:** NÃO recebe lat/lng. Coerce `alunos_por_m2`,
  filtra finito>0; janela ±20% → ±50% → base inteira (por `metragem` se presente); percentis
  p10/p50/p90 × m2. Degrada para dict com Nones + `n_comparaveis=0` se base ausente/sem coluna/vazia.
- **`flag_zona_morta(catch_dict, ...)`:** lê `pop_captacao`/`renda_per_capita_captacao` do dict
  de catchment; `None`/NaN → `{"flag_zona_morta": None, "motivo_zona_morta": "catchment_indisponivel"}`;
  dispara True se pop<min OU renda<min, motivo `"ok"` caso contrário. NÃO prevê alunos.
- **`grade_sensibilidade(m2, aluguel_ref, demanda_premissa, ...)`:** varredura cartesiana
  alunos×fator-de-aluguel → `viabilidade()` por par; DataFrame com colunas
  `[alunos, aluguel, fator_aluguel, margem_liq, viavel, payback]`. `demanda_premissa`/`margem_alvo`
  na assinatura por simetria (não varridos).
- **`analisar_viabilidade_ponto(lat, lng, m2, aluguel_pedido, demanda_premissa, ...)`:** orquestrador.
  Catchment só roda se `setores_df` injetado (senão `catch=None` → flag/pop/renda None);
  viabilidade no cenário pedido usa `demanda_premissa` (nunca geo); aluguel-teto + break-even via
  goal-seek do simulador; grade de sensibilidade. Retorna `ViabilidadePontoResult` com
  `demanda_fonte` hardcoded `"premissa_explicita"`.
- **`__all__`** com símbolos públicos + constantes.

Decisões de implementação:
- catchment retorna **dict** (não dataclass) — acesso via `["pop_captacao"]`. Confirmado em
  `catchment_batch.py`.
- `RAIO_CATCHMENT_KM` **existe** em `dimensionamento/config.py` (=1.5) — importado direto.
- `# type: ignore[arg-type]` nas chamadas com `**kwargs` a `viabilidade`/`aluguel_teto`/
  `alunos_minimos_viaveis` (mesmo padrão do `simulador.py`).
- `flag_zona_morta` coage pop/renda a `float | None` upfront para o mypy narrow os comparadores.
- `__init__.py` do pacote NÃO tocado (não necessário para os testes).
