## Resultados do pipeline real
Pipeline executado com os parquets reais (censo ~1.17 GB carregado). Relatório materializado em `data/analysis/residual_discriminacao.md` (gitignored).
- Enriquecimento: N com coord=275, N hex match=275, N com alunos=373; N viáveis=231, N inviáveis=142.
- **Teste B — VEREDITO = NO-GO (honesto):**
  - AUC residual = **0.4801** | IC95 [0.4233, 0.5354] (cruza 0.5).
  - AUC baseline (pop×renda) = 0.5318 | AUC penetração LOO = 0.3296.
  - delta_auc (residual − baseline) = **−0.0517** | p-perm = 0.739 | n_bootstrap_validos=1000.
  - Leitura: o `score_oportunidade_residual` NÃO discrimina viável×inviável melhor que acaso, e fica ABAIXO do baseline pop×renda. Consistente com a DEC-001 (sinal residual fraco). NO-GO é resultado válido — não forçado.
- **Teste C — decomposição de variância** (método ols_dummies, n_efetivo=367, R²=0.464):
  - var. explicada região = **0.338** | marca = 0.068 | **domínio = 0.059**.
  - coef domínio = −0.0410 | uplift = −4.02%/unidade de marca no raio.
  - Leitura: a estrutura é dominada por REGIÃO (33.8%); o domínio de marca própria no catchment explica pouco (5.9%) e com sinal negativo — não sustenta a tese "domínio puxa penetração".
- **Sanidade:** TNR = 0.22 (só 22% dos inviáveis caem no quartil inferior do residual) — reforça o NO-GO do Teste B.
