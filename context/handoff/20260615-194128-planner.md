## Resumo do objetivo
Criar o módulo isolado `src/motor_expansao/dimensionamento/viabilidade_ponto.py`: dado um
imóvel real (`lat,lng` + `m²` + `aluguel pedido` + `demanda_premissa`), devolver contexto do

zona morta. A faixa de alunos por densidade depende SÓ de `m²` + base de comparáveis — não de geo.

### 3. Função `faixa_alunos_por_densidade`

```python
def faixa_alunos_por_densidade(
    m2: float,
    base_calibracao_df: pd.DataFrame,
    *,
    tolerancia: float = FAIXA_M2_TOLERANCIA,
    tolerancia_alargada: float = FAIXA_M2_TOLERANCIA_ALARGADA,
    n_min: int = N_MIN_COMPARAVEIS,
) -> dict:
    """Faixa de alunos plausível derivada da curva tamanho→densidade (NÃO geográfica).

    Usa `alunos_por_m2` dos comparáveis Ultra numa janela de m² em torno do imóvel.
    Retorna percentis (p10/p50/p90) de `alunos_por_m2` × m² -> faixa de ALUNOS.

    GUARDRAIL: não recebe lat/lng. A faixa depende SÓ de `m²` + base de comparáveis.

    Janela:
      1. ±`tolerancia` (20%) do m² do imóvel.
      2. Se N < `n_min`: alarga para ±`tolerancia_alargada` (50%).
      3. Se ainda N < `n_min`: usa a base inteira.

    Retorna dict:
      {"faixa_alunos_p10": float, "faixa_alunos_p50": float, "faixa_alunos_p90": float,
       "n_comparaveis": int}
    ou, se a base não tiver as colunas exigidas ou ficar vazia após limpeza:
      {"faixa_alunos_p10": None, ..., "n_comparaveis": 0}
    """
```

Lógica passo a passo:
1. Validação defensiva: se `base_calibracao_df is None` ou vazio, **ou** se faltar a coluna
   `alunos_por_m2`, retornar dict com os 3 percentis `None` e `n_comparaveis=0`. (A coluna de
   metragem pode chamar `metragem` — checar presença; sem ela, não dá para filtrar por janela,
   então usar a base inteira para os percentis, com `n_comparaveis = N válido`.)
2. Coerção: `apm = pd.to_numeric(df["alunos_por_m2"], errors="coerce")`; manter só linhas com
   `apm` finito e `> 0`. Se houver coluna `metragem`, coerção análoga.
3. Função interna `_janela(tol)`: se `metragem` existe, filtra
   `metragem.between(m2*(1-tol), m2*(1+tol))`; senão devolve toda a base válida.
4. Tentar janela estreita (`tolerancia`). Se `len < n_min`, tentar `tolerancia_alargada`. Se ainda
   `len < n_min`, usar toda a base válida.
5. Se após tudo o subconjunto ficar vazio → retornar os 3 percentis `None`, `n_comparaveis=0`.
6. Percentis: `p10, p50, p90 = np.percentile(apm_sub, [10, 50, 90])`.
7. Multiplicar por `m2`: `faixa_alunos_pXX = float(pXX * m2)`.
8. Retornar dict com os 3 valores (float) e `n_comparaveis = int(len(apm_sub))`.

Sem escrita em disco, sem PII (só lê `alunos_por_m2` / `metragem`).

### 4. Função `flag_zona_morta`

```python
def flag_zona_morta(
    catchment_result: Optional[dict],
    *,
    pop_min: float = POP_ZONA_MORTA_MIN,
    renda_min: float = RENDA_ZONA_MORTA_MIN,
) -> dict:
    """Sinaliza risco de contexto (zona morta) a partir do catchment — NÃO prevê alunos.

    Lê `pop_captacao` e `renda_per_capita_captacao` do dict de catchment.
    Dispara True se pop < pop_min OU renda < renda_min.

    Retorna {"flag_zona_morta": Optional[bool], "motivo_zona_morta": Optional[str]}.
    Se catchment_result is None (sem setores) ou pop/renda forem NaN -> retorna
    {"flag_zona_morta": None, "motivo_zona_morta": "catchment_indisponivel"}.
    """
```

Lógica:
1. Se `catchment_result is None` → `{"flag_zona_morta": None, "motivo_zona_morta": "catchment_indisponivel"}`.
2. Ler `pop = catchment_result.get("pop_captacao")`, `renda = catchment_result.get("renda_per_capita_captacao")`.
3. Se ambos NaN/None (`not np.isfinite`) → `{"flag_zona_morta": None, "motivo_zona_morta": "catchment_indisponivel"}`.
4. Montar lista de motivos: se `np.isfinite(pop)` e `pop < pop_min` → append `f"pop<{int(pop_min)}"`;
   se `np.isfinite(renda)` e `renda < renda_min` → append `f"renda<{int(renda_min)}"`.
5. `flag = bool(motivos)`; `motivo = "; ".join(motivos) if motivos else "ok"`.
6. Retornar `{"flag_zona_morta": flag, "motivo_zona_morta": motivo}`.

**GUARDRAIL:** esta função NÃO prevê demanda — só compara pop/renda do entorno com thresholds
exógenos. A flag é de exclusão de contexto, não estimativa de alunos.

### 5. Função `grade_sensibilidade`

```python
def grade_sensibilidade(
    m2: float,
    aluguel_ref: float,
    demanda_premissa: float,
    *,
    ticket_medio: float = SIM_MENSALIDADE_BALCAO,
    n_alunos_range: tuple[float, ...] = ALUNOS_RANGE_DEFAULT,
    n_aluguel_range: tuple[float, ...] = ALUGUEL_RANGE_FATOR,
    margem_alvo: float = 0.10,
    **kwargs: object,
) -> pd.DataFrame:
    """Varredura cartesiana alunos × aluguel -> viabilidade() por par.

    `n_alunos_range` é uma grade ABSOLUTA de alunos (não inclui demanda_premissa
    automaticamente; o orquestrador a usa como referência separada).
    `n_aluguel_range` são FATORES multiplicados por `aluguel_ref`.

    Retorna DataFrame com colunas:
      ['alunos', 'aluguel', 'fator_aluguel', 'margem_liq', 'viavel', 'payback'].
    Shape = (len(n_alunos_range) * len(n_aluguel_range), 6).
    """
```

Lógica:
1. `linhas: list[dict] = []`.
2. Loop cartesiano `for alunos in n_alunos_range: for fator in n_aluguel_range:`:
   - `aluguel = float(aluguel_ref) * float(fator)`
   - `r = viabilidade(float(alunos), m2, aluguel, ticket_medio, **kwargs)`  # type: ignore[arg-type]
   - append `{"alunos": float(alunos), "aluguel": aluguel, "fator_aluguel": float(fator),
     "margem_liq": r.margem_ebitda_pct, "viavel": r.flag_viavel, "payback": r.payback_meses}`.
3. Retornar `pd.DataFrame(linhas)` (com ordem de colunas garantida via
   `pd.DataFrame(linhas, columns=[...])`).

Notas:
- `demanda_premissa` é parâmetro da assinatura (para o orquestrador poder reusar e por simetria
  com o task-spec), mas a grade varre `n_alunos_range` — `demanda_premissa` NÃO entra na varredura.
  Mantê-lo na assinatura sem usá-lo no loop é intencional (referência); marcar como usado em
  docstring para não disparar lint de arg não usado — se ruff reclamar de arg não usada, é falso
  positivo (args de assinatura pública não disparam F841/ARG por padrão no ruff; OK).
- `margem_liq` = `margem_ebitda_pct` do simulador (nome "liq" no contrato do task-spec; documentar
  que é a margem EBITDA do DRE).
- `**kwargs` repassados a `viabilidade()` (ex.: `capex`, `coef_capex_m2`, `alunos_agregadores`).
- `margem_alvo` fica na assinatura por simetria mas só é relevante se você quiser uma coluna extra;
  manter como parâmetro aceito mas não usado na grade (não criar coluna dependente dele aqui).

### 6. Função orquestradora `analisar_viabilidade_ponto`

```python
def analisar_viabilidade_ponto(
    lat: float,
    lng: float,
    m2: float,
    aluguel_pedido: float,
    demanda_premissa: float,
    *,
    ticket_medio: float = SIM_MENSALIDADE_BALCAO,
    margem_alvo: float = 0.10,
    raio_km: float = RAIO_CATCHMENT_KM,
    base_calibracao_df: Optional[pd.DataFrame] = None,
    setores_df: Optional[pd.DataFrame] = None,
    alunos_range: tuple[float, ...] = ALUNOS_RANGE_DEFAULT,
    aluguel_range_fator: tuple[float, ...] = ALUGUEL_RANGE_FATOR,
    **kwargs: object,
) -> ViabilidadePontoResult:
    """Orquestrador property-first.

    GUARDRAIL: demanda_premissa é entrada do operador; NUNCA derivada de lat/lng.
    lat/lng entram SÓ no catchment (contexto pop/renda) e na flag de zona morta.

    Modos degradados:
      - setores_df is None  -> catchment NÃO roda; flag_zona_morta=None,
        pop_captacao/renda_per_capita_captacao=None.
      - base_calibracao_df is None -> faixa_alunos_p10/p50/p90=None, n_comparaveis=None.
    """
```

Lógica passo a passo:
1. **Catchment (contexto):**
   - Se `setores_df is None`: `catch = None`; `pop=None`; `renda=None`.
   - Senão: `catch = calcular_catchment_unidade(lat, lng, setores_df, raio_km=raio_km)`;
     `pop = catch["pop_captacao"]`; `renda = catch["renda_per_capita_captacao"]`.
     Converter NaN → manter como float NaN nos campos `pop_captacao`/`renda_per_capita_captacao`
     (ou `None` se preferir; **decisão: manter o valor numérico do catchment, mesmo NaN**, para
     fidelidade; quando `setores_df is None`, aí sim `None`).
2. **Flag de zona morta:**
   - `zm = flag_zona_morta(catch, pop_min=POP_ZONA_MORTA_MIN, renda_min=RENDA_ZONA_MORTA_MIN)`
     (passa `catch` que é `None` quando sem setores → retorna flag/motivo `None`/`"catchment_indisponivel"`).
3. **Faixa de alunos por densidade:**
   - Se `base_calibracao_df is None`: `faixa = {"faixa_alunos_p10": None, "faixa_alunos_p50": None,
     "faixa_alunos_p90": None, "n_comparaveis": None}`.
   - Senão: `faixa = faixa_alunos_por_densidade(m2, base_calibracao_df)`.
4. **Viabilidade no cenário pedido (demanda = premissa explícita):**
   - `viab = viabilidade(demanda_premissa, m2, aluguel_pedido, ticket_medio, **kwargs)`  # type: ignore[arg-type]
5. **Aluguel-teto e break-even:**
   - `teto = aluguel_teto(demanda_premissa, m2, ticket_medio, margem_alvo=margem_alvo, **kwargs)`  # type: ignore[arg-type]
   - `breakeven = alunos_minimos_viaveis(m2, aluguel_pedido, ticket_medio, margem_alvo=margem_alvo, **kwargs)`  # type: ignore[arg-type]
6. **Grade de sensibilidade:**
   - `grade = grade_sensibilidade(m2, aluguel_pedido, demanda_premissa, ticket_medio=ticket_medio,
     n_alunos_range=alunos_range, n_aluguel_range=aluguel_range_fator, margem_alvo=margem_alvo, **kwargs)`
7. **Montar e retornar `ViabilidadePontoResult`** com todos os campos:
   - `lat`, `lng`, `m2`, `aluguel_pedido`, `demanda_premissa` ecoados (float).
   - `faixa_alunos_p10/p50/p90` e `n_comparaveis` do dict `faixa`.
   - `flag_zona_morta`, `motivo_zona_morta` do dict `zm`.
   - `pop_captacao`, `renda_per_capita_captacao`: `None` se `catch is None`, senão `float(pop)`/`float(renda)`.
   - `viabilidade=viab`, `aluguel_teto_calculado=float(teto)`, `alunos_breakeven=float(breakeven)`.
   - `grade_sensibilidade=grade`.
   - `demanda_fonte=DEMANDA_FONTE_PREMISSA` (default; deixar explícito ou via default do dataclass).

**Não chamar nenhum `read_parquet`** dentro do módulo. Todos os DataFrames vêm injetados.
