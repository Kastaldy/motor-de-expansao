VERSAO_CONTRATO_OVERLAP = "overlap_nao_abra_v1"

**Função `_to_hex(lat, lng) -> str | None`:**
- Converte `(lat, lng)` para hex H3 res-7 usando `h3.latlng_to_cell`.
- Retorna `None` se inválido (try/except ValueError/TypeError).
- Reutiliza o mesmo padrão de `concorrentes_densos._to_cell`.

**Função `_ler_smartfit(fonte: Path) -> pd.DataFrame`:**
- Lê `01_SmartFit.xlsx` (colunas `ID`, `Nome`, `Latitude`, `Longitude`).
- Deriva `hex_id` via `_to_hex`.
- Dropa `ID`, `Nome`, `Latitude`, `Longitude` imediatamente após derivar hex (drop-PII na fronteira).
- Retorna DataFrame com apenas `hex_id` (sem NaN). Nunca persiste colunas textuais.

**Função `_ler_competidores(fonte: Path) -> pd.DataFrame`:**
- Lê `03_Competidores.xlsx` (colunas `Latitude`, `Longitude`, `Nome_Academia`, mais outras ignoradas).
- Deriva `hex_id` via `_to_hex`.
- Classifica a rede via `classificar_rede(Nome_Academia)` — SOMENTE em memória.
- Dropa `Nome_Academia`, `Latitude`, `Longitude`, `Cluster_ID`, `Total_Alunos_Cluster`, `Total_Academias`, `Alunos_Academia`, `Município`, `Plano` imediatamente após derivar hex+rede.
- Retorna DataFrame com apenas `hex_id` e `rede_normalizada` (sem NaN em hex_id).
- Nota: coords 1–2 decimais causam imprecisão de hex (caveat documentado no relatório, não corrigido aqui).

**Função `calcular_metricas_smartfit(df_sf: pd.DataFrame, df_denso: pd.DataFrame) -> dict`:**
- Recebe o frame já processado (hex_id) e o parquet denso lido.
- Filtra `df_denso` pela `rede_normalizada == REDE_SMARTFIT`.
- Calcula:
  - `hexes_sf` = set de hex_id únicos do 01_SmartFit (após drop-PII).
  - `hexes_denso_sf` = set de hex_id únicos da base densa com `rede_normalizada == "smart_fit"`.
  - `intersecao` = `hexes_sf & hexes_denso_sf`.
  - `recall` = `len(intersecao) / len(hexes_sf)` (se `len(hexes_sf) > 0`).
  - `n_sf_total` = `len(hexes_sf)`.
  - `n_denso_sf` = `len(hexes_denso_sf)`.
  - `n_intersecao` = `len(intersecao)`.
  - `n_sf_ausentes_da_densa` = hexes no 01_SmartFit mas não na base densa (= `len(hexes_sf - hexes_denso_sf)`).
  - `n_densa_sem_sf` = hexes na base densa SmartFit sem correspondente no 01_SmartFit (= `len(hexes_denso_sf - hexes_sf)`).
- Retorna dict com todas essas métricas.

**Função `calcular_metricas_competidores(df_comp: pd.DataFrame, df_denso: pd.DataFrame) -> dict`:**
- Recebe o frame já processado (`hex_id`, `rede_normalizada`) e o parquet denso.
- Constrói `pares_comp` = set de `(hex_id, rede_normalizada)` únicos do 03_Competidores.
- Constrói `pares_denso` = set de `(hex_id_res7, rede_normalizada)` únicos da base densa.
- Calcula métricas globais:
  - `n_pares_comp_total` = `len(pares_comp)`.
  - `n_pares_denso_total` = `len(pares_denso)`.
  - `n_intersecao` = `len(pares_comp & pares_denso)`.
  - `recall_global` = `n_intersecao / n_pares_comp_total` (se > 0).
- Calcula métricas por rede (excluindo `independente` da análise de recall granular porque não é classificável 1:1):
  - Para cada rede conhecida no df_comp (lista de redes != `independente`): recall por rede.
  - Também apura `n_linhas_comp_por_rede` (contagem bruta de linhas do 03_Competidores por rede).
  - Especificamente, calculra `n_skyfit_classificado_como_independente` = contagem de linhas em `df_comp` onde a rede classificada é `independente` mas a `rede_normalizada` original poderia ser SKYFIT — **atenção**: como já fizemos drop-PII do nome, esse número não é calculável post-hoc. A solução: antes do drop do nome, calcular um contador específico `n_skyfit_nao_reconhecido` = número de linhas onde o nome normalizado contém "skyfit" mas `classificar_rede` retornou `independente`. Este contador é calculado em `_ler_competidores` (em memória, nunca persistido) e retornado como coluna auxiliar extra no dict (não no DataFrame final).

  **Implementação correta de `_ler_competidores`:** retorna também `n_skyfit_nao_reconhecido` como valor separado (não coluna), via tupla `(df, n_skyfit)` ou atributo adicional. Mais simples: retornar `(df_sem_pii, n_skyfit_nao_reconhecido: int)`.

- Retorna dict com métricas globais + `tabela_por_rede` (lista de dicts com `rede`, `n_pares_comp`, `n_intersecao`, `recall`).

**Função `_assert_sem_pii_relatorio(texto: str) -> None`:**
- Rede de segurança: falha se o texto do relatório contiver qualquer string de `_NOMES_PROIBIDOS_RELATORIO` como coluna/campo (verifica os headers de tabela markdown, não o conteúdo genérico).
- Mais precisamente: garante que o relatório não contém colunas `Nome`, `Nome_Academia`, `ID` como headers de tabela markdown (`| Nome |`). Implementar como check simples: se `"| Nome "` ou `"| nome "` etc. aparece no texto → raise.

**Função `gerar_relatorio(metricas_sf: dict, metricas_comp: dict, n_skyfit_nao_reconhecido: int, df_denso_info: dict, destino: Path, *, escrever: bool = True) -> str`:**
- Monta o relatório em Markdown (PT-BR, sem PII).
- Estrutura do relatório:
  1. Header e disclaimers (READ-ONLY M1, DEC-012, sem PII).
  2. Seção "Resumo da base densa": total de pares e redes (do `df_denso_info`).
  3. Seção "Recall vs 01_SmartFit.xlsx": tabela com `n_sf_total`, `n_denso_sf`, `n_intersecao`, `n_sf_ausentes_da_densa`, `n_densa_sem_sf`, `recall` (%).
  4. Seção "Recall/overlap vs 03_Competidores.xlsx": recall global, tabela por rede (só redes conhecidas), nota de caveat sobre imprecisão de coords (1–2 decimais → viés de hex → recall artificialmente baixo), nota de caveat sobre gap de token SKYFIT (`n_skyfit_nao_reconhecido` linhas com "skyfit" classificadas como `independente`; base densa tem `skyfit` via `fonte=unidades`).
  5. Seção "Recomendação": síntese sobre suficiência da base densa para o Huff.
- Chama `_assert_sem_pii_relatorio(texto)` antes de escrever.
- Se `escrever=True`, cria diretório pai e escreve o arquivo.
- Retorna o texto.

**Função `executar(smartfit_path, competidores_path, densos_path, destino, *, escrever=True) -> str`:**
- Orquestrador. Lê `df_denso` do parquet (READ-ONLY, não reescreve).
- Chama `_ler_smartfit`, `_ler_competidores` (recebe `(df_comp, n_skyfit)`), `calcular_metricas_smartfit`, `calcular_metricas_competidores`.
- Monta `df_denso_info = {"n_pares": len(df_denso), "n_redes": df_denso["rede_normalizada"].nunique()}`.
- Chama `gerar_relatorio`.
- Retorna o texto do relatório.
- Decorator `# pragma: no cover` NÃO aplicado — o orquestrador será testado via injeção de dados sintéticos.

**`__all__`** deve exportar: `executar`, `calcular_metricas_smartfit`, `calcular_metricas_competidores`, `gerar_relatorio`, `RELATORIO_DEFAULT`, `SMARTFIT_DEFAULT`, `COMPETIDORES_DEFAULT`, `DENSOS_DEFAULT`, `VERSAO_CONTRATO_OVERLAP`.

## Riscos técnicos

- **`openpyxl` nos testes:** `pd.DataFrame.to_excel` requer `openpyxl`. Se não estiver no ambiente, substituir fixture por CSV ou mockar a leitura. Verificar com `python -c "import openpyxl"` antes de implementar.
- **`_ler_competidores` retornando tupla vs DataFrame:** a mudança de assinatura para retornar `(df, n_skyfit)` impacta o orquestrador `executar`. O Builder deve manter consistência entre a assinatura da função e todos os seus chamadores.
- **Imprecisão de coords em 03_Competidores (1–2 decimais):** o join por hex res-7 vai subestimar recall. Os testes devem usar coords de alta precisão para evitar flakiness; o caveat é documentado no relatório, não contornado no código.
- **`data/staging/concorrentes_densos.parquet` ausente no CI:** o teste `test_densos_parquet_nao_reescrito` usa `tmp_path` (não o parquet real), portanto é seguro em CI.
- **Coluna `hex_id_res7` vs `hex_id`:** a base densa usa `hex_id_res7` como nome de coluna; o 03_Competidores usa `hex_id` derivado internamente. O Builder deve usar `hex_id_res7` para ler o parquet denso e fazer o join corretamente.
