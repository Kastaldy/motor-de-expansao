## Forma da execução (7 fases, 27 agentes, 0 erros, ~3,3 M tokens de sub-agente)

1. **Verdade** (1 agente) — âncora factual única extraída do CÓDIGO: 8 páginas, 23 fatos com
   evidência arquivo:linha, 16 armadilhas. Barreira deliberada: se cada corretor derivasse os
   fatos por conta própria, os 4 docs divergiriam entre si — que é exatamente o defeito que este
   bloco existe para eliminar.
2. **Auditar** (4 agentes, 1 por doc) — cada afirmação falsa listada com linha, texto literal,
   razão e texto corrigido. Cada auditor também produziu `ja_corretos`: os trechos que PARECEM
   stale mas são **histórico verdadeiro** e não podem ser tocados. Essa lista foi o que protegeu
   a cronologia por bloco.
3. **Corrigir** (4 agentes) — aplicação cirúrgica, com direito a REJEITAR achado da auditoria.
4. **Renomear** (1 agente) — 8 nomes de teste stale.
5. **Verificar** (12 agentes = 4 docs × 3 lentes) — céticos instruídos a REFUTAR, com lentes
   distintas: factual (contra o código), consistência interna (o doc se contradiz? a aritmética
   7→5→6→7→8 fecha?) e **dano colateral no diff** (o corretor apagou informação boa? quebrou
   convenção de acentuação? quebrou o YAML?). Resultado: **56 defeitos apontados, 13 bloqueantes**.
6. **Reparar** (4 agentes) — aplicaram o que confirmaram; rejeitaram o que não procedia.
7. **Completude** (1 agente) — veredito **PRONTO_COM_RESSALVAS**, `diff_limpo: true`, 9 pendências.
