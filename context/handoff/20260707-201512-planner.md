**Função 1 — `ler_imoveis_xlsx(path: Path | str) -> pd.DataFrame`**

- Assinatura: `def ler_imoveis_xlsx(path: Path | str) -> pd.DataFrame:`
- Usa `pd.read_excel(Path(path), sheet_name="Imóveis", header=2)` (linha 0 = título, linha 1 = vazia, linha 2 = cabeçalho real).
- Após leitura, valida que `set(COLUNAS_ESPERADAS).issubset(df.columns)`: se falhar, levanta `ValueError` com as colunas faltantes.
- Retorna o DataFrame bruto (sem nenhuma limpeza — a limpeza é responsabilidade de `validar_e_limpar`).
- Sem side-effects. Não grava nada.

**Função 2 — `validar_e_limpar(df: pd.DataFrame) -> tuple[pd.DataFrame, dict[str, int]]`**

- Assinatura: `def validar_e_limpar(df: pd.DataFrame) -> tuple[pd.DataFrame, dict[str, int]]:`
- Retorna `(df_limpo, resumo)` onde `resumo` é um dict com chaves:
  - `"total_entrada"`: int — linhas antes de qualquer filtro
  - `"descartados_area"`: int — linhas descartadas por `ÁREA < 500`
  - `"descartados_placeholder"`: int — linhas descartadas por aluguel placeholder (`abs(ALUGUEL - 11111.11) < 0.01`)
  - `"descartados_aluguel_fora_range"`: int — linhas descartadas por aluguel fora de `[10.000, 500.000]` (APÓS remover placeholder)
  - `"total_limpo"`: int — linhas no df_limpo
  - `"sem_coord"`: int — linhas de df_limpo onde `flag_sem_coord=True`
- **Ordem de aplicação dos filtros** (sequencial, cada filtro opera sobre o df residual):
  1. Descartar `ÁREA < AREA_MIN_M2` (float; `df["ÁREA"].astype(float) < 500.0`).
  2. Descartar placeholder: `abs(df["ALUGUEL"].astype(float) - ALUGUEL_PLACEHOLDER) < PLACEHOLDER_TOLERANCIA`.
  3. Descartar aluguel fora de range: `~df["ALUGUEL"].astype(float).between(ALUGUEL_MIN, ALUGUEL_MAX, inclusive="both")`.
- **Adicionar coluna `flag_sem_coord`** (bool): `True` quando `LATITUDE` é NaN **ou** `LONGITUDE` é NaN. Usar `pd.isna(df["LATITUDE"]) | pd.isna(df["LONGITUDE"])`.
- **NÃO descartar** linhas com `flag_sem_coord=True`.
- **Preservar coluna `STATUS`** intacta com os valores originais dos sobreviventes.
- `df_limpo` deve conter TODAS as colunas originais + `flag_sem_coord`.
- Reset de índice no df_limpo: `df_limpo.reset_index(drop=True)`.

**Função 3 — `materializar(df_limpo: pd.DataFrame, resumo: dict[str, int], staging_dir: Path | str, analysis_dir: Path | str) -> tuple[Path, Path]`**

- Assinatura: `def materializar(df_limpo: pd.DataFrame, resumo: dict[str, int], staging_dir: Path | str, analysis_dir: Path | str) -> tuple[Path, Path]:`
- Retorna `(path_parquet, path_relatorio)`.
- Cria os diretórios se não existirem (`mkdir(parents=True, exist_ok=True)`).
- Salva `df_limpo.to_parquet(staging_dir / "imoveis_candidatos_limpos.parquet", index=False)`.
- Gera `data/analysis/imoveis_qualidade.md` com o seguinte conteúdo (usar f-string ou template literal):

```
# Relatório de Qualidade — Imóveis Candidatos

Gerado em: {datetime.now().strftime("%Y-%m-%d %H:%M:%S")}

## Resumo por regra de limpeza

| Regra | Descartados |
|---|---|
| Área < 500 m² | {resumo["descartados_area"]} |
| Aluguel placeholder (11.111,11) | {resumo["descartados_placeholder"]} |
| Aluguel fora de [10.000, 500.000] | {resumo["descartados_aluguel_fora_range"]} |

## Totais

| Métrica | Valor |
|---|---|
| Total de entrada | {resumo["total_entrada"]} |
| Total limpo (sobreviventes) | {resumo["total_limpo"]} |
| Sem coordenada (flag_sem_coord=True) | {resumo["sem_coord"]} |
| % sem coordenada | {pct_sem_coord:.1f}% |

## Observação

Registros sem coordenada recebem `flag_sem_coord=True` e são MANTIDOS no parquet
limpo. O geocoding é passo humano separado (BLK-VIAB-03). Nenhum dado de
coordenada de pessoa física é processado — os imóveis são endereços comerciais.
```

Onde `pct_sem_coord = 100 * resumo["sem_coord"] / resumo["total_limpo"]` (proteger divisão por zero: se `total_limpo == 0`, usar 0.0).

- Gravar o markdown com `encoding="utf-8"` (não `utf-8-sig`, pois é relatório interno, não CSV de usuário).

**Função 4 — `run(xlsx_path: Path | str, staging_dir: Path | str = Path("data/staging"), analysis_dir: Path | str = Path("data/analysis")) -> tuple[Path, Path]`**

- Assinatura: `def run(xlsx_path: Path | str, staging_dir: Path | str = Path("data/staging"), analysis_dir: Path | str = Path("data/analysis")) -> tuple[Path, Path]:`
- Orquestra: `ler_imoveis_xlsx` → `validar_e_limpar` → `materializar`.
- Retorna `(path_parquet, path_relatorio)`.
- Serve como ponto de entrada para CLI ou script externo.

## Riscos técnicos

- **`header=2`**: se o Builder usar `header=0` (padrão), as duas primeiras linhas viram dados e as colunas serão o título do relatório. Verificar sempre com `df.columns.tolist()` no teste de smoke.
- **ÁREA como float**: valores `14.9` e `25.63` são floats; a comparação `< 500` deve ser `< 500.0` (usar float explícito para clareza de tipos).
- **Placeholder 11111.11**: usar `abs(val - 11_111.11) < 0.01`, NÃO `val == 11111.11` (comparação float exata pode falhar com diferentes locales ou codificações do xlsx).
- **Coluna `ALUGUEL` pode chegar como string em locales alternativos**: usar `pd.to_numeric(df["ALUGUEL"], errors="coerce")` antes dos filtros numéricos para robustez.
- **Zero coordenadas no snapshot atual**: todos os 23 sobreviventes do xlsx real terão `flag_sem_coord=True`; o teste de `flag_sem_coord=False` (ID 1 na fixture sintética) garante que o caminho feliz funciona em snaps futuros.
- **`openpyxl` não instalado**: improvável (já usado em outros módulos), mas se falhar em CI verificar dependências extras no `pyproject.toml`.
