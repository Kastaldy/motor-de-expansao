   `result["zonas_geo"]` é uma lista de dicts produzida por `_zonas_geometricas` (linhas

   **Invariante do algoritmo de zonificação** (linhas 506-513 de `_zonas_geometricas`,
   `zona = min(2, (idx * 3) // n)` com `idx` crescente por distância): a lista de zonas

   combinações: `{}` (0 zonas), `{Âncora}` (1 zona, N aprovados = 1), `{Âncora, Flancos}`

   O helper deve, ainda assim, ser escrito de forma DEFENSIVA (não assumir a invariante
   silenciosamente): verificar por PERTENCIMENTO de rótulo (não por índice/posição), testando
   da combinação "mais completa" para a "menos completa" (ver passo 4). Caso 0 zonas
   (`zonas_geo` vazio/None) → fallback dedicado.

       zona geometrica PRESENTES em result["zonas_geo"] (SO LEITURA; nao recalcula zonas).

       mudancas futuras no algoritmo)."""
