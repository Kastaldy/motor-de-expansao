### 2. Funções puras a criar (assinaturas exatas)
Manter puras (recebem DataFrame/arrays, não leem disco) para testabilidade:

1. `def pairwise_valid(df: pd.DataFrame, score_col: str, outcome_col: str = OUTCOME) -> pd.DataFrame:`
   Retorna sub-DataFrame só com linhas onde `score_col` E `outcome_col` são ambos não-nulos (após `pd.to_numeric(..., errors="coerce")`). Não muta entrada.

2. `def correlate(x: pd.Series, y: pd.Series, *, n_min: int = N_MIN) -> dict:`
   Núcleo do cálculo. Coerção numérica + drop pairwise interno (defensivo). Retorna dict com chaves estáveis: `{"n": int, "spearman_rho": float|None, "spearman_p": float|None, "pearson_r": float|None, "pearson_p": float|None, "suficiente": bool}`. Se `n < n_min` → `suficiente=False` e coefs/p = None (não chamar scipy). Se `n >= n_min` mas a série tiver variância zero (constante) → coefs = None com flag `"motivo": "variancia_zero"` (scipy retorna nan; tratar e não quebrar). Usa `stats.spearmanr` e `stats.pearsonr`.

3. `def correlate_by_cell(df: pd.DataFrame, score_col: str, *, by: str | None = "rede", outcome_col: str = OUTCOME, n_min: int = N_MIN) -> list[dict]:`
   Aplica `correlate` no agregado (`by=None` → célula "AGG") e por valor de `by` (cada rede). Cada item adiciona `{"celula": <"AGG"|rede>, "score": score_col}`. Para domínio×engcorpo (N=4) sairá `suficiente=False`.

4. `def bootstrap_ci_spearman(x: pd.Series, y: pd.Series, *, n_boot: int = N_BOOT, seed: int = SEED) -> tuple[float, float] | None:`
   IC percentil 2.5/97.5 do Spearman via reamostragem com `np.random.default_rng(seed)`. Retorna None se N < 30 (não aplicar a células pequenas). Determinístico pelo seed. OPCIONAL no relatório.

5. `def join_componentes(dataset: pd.DataFrame, priorizados: pd.DataFrame) -> tuple[pd.DataFrame, dict]:`
   Left-join read-only de `renda_pct_nacional`/`pop_pct_nacional` por `hex_id` (priorizados já tem `hex_id` único, 0 duplicados — confirmado: shape 307.579×19, dup=0). Seleciona do priorizados só `["hex_id","renda_pct_nacional","pop_pct_nacional"]`. Retorna `(df_merged, match_stats)` onde `match_stats = {"linhas_com_hex": int, "casadas": int, "match_rate_pct": float}`. NÃO sobrescreve nenhuma coluna do dataset.

6. `def decompor_renda_pop(df_merged: pd.DataFrame, *, outcome_col: str = OUTCOME, n_min: int = N_MIN) -> dict:`
   Correlaciona ISOLADAMENTE `renda_pct_nacional` vs outcome e `pop_pct_nacional` vs outcome (agg e por rede), via `correlate`. Também correlaciona `score_priorizacao` vs outcome nas MESMAS linhas casadas (para contextualizar). Retorna estrutura `{"renda": [...], "pop": [...], "priorizacao_nas_casadas": [...], "match_stats": {...}}`. É a base do item (b). REGRA DURA: este achado é DESCRITIVO — proibido derivar/sugerir novo peso no texto.

7. `def find_outliers(df: pd.DataFrame, score_col: str, *, outcome_col: str = OUTCOME, k: int = 3) -> dict:`
   Identifica casos score-alto×desfecho-baixo e vice-versa. Método determinístico: converter `score_col` e `outcome_col` em percentis (`rank(pct=True)`) DENTRO de rede (preferir within-rede por heterogeneidade de desfecho); discrepância = `|pct_score - pct_outcome|`. Retornar top-`k` "score alto (>=0.7) & outcome baixo (<=0.3)" e top-`k` inverso. Saída AGREGADA/anonimizada para o relatório: por linha expor só `rede`, `uf`, `nome_municipio`, `hex_id`, `hex_precisao`, `rotulo_confiabilidade`, percentis e valores — NÃO expor `nome_unidade` (PII). Cada caso acompanha campo `hipotese` textual padrão a partir de heurística (ver item de relatório).

8. `def build_report(...) -> str:` — monta o markdown (string). Recebe os resultados das funções acima + `match_stats` + metadados de N. Sem I/O.

9. `def load_inputs(dataset_path=DATASET_PARQUET, priorizados_path=PRIORIZADOS_PARQUET) -> tuple[pd.DataFrame, pd.DataFrame]:`
   Único ponto de leitura de disco. `pd.read_parquet`. Priorizados lido só com as 3 colunas necessárias (`columns=["hex_id","renda_pct_nacional","pop_pct_nacional"]`) para ser leve. Read-only.

10. `def main(argv: list[str] | None = None) -> int:` — orquestra: load → join → correlações por score → decomposição → outliers → (figuras opcionais em try/except) → `build_report` → grava `OUT_REPORT` com `encoding="utf-8"`. `print` só agregados (sem PII). `return 0` sempre que chegar ao fim. Guard `if __name__ == "__main__": sys.exit(main())`.
