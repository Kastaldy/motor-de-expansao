## O que foi feito

### Fase A — Tema/layout CSS injetado

**`src/motor_expansao/dashboard/ui_theme.py`** (novo):
- `inject_ultra_theme()`: injeta CSS via `st.markdown(unsafe_allow_html=True)`.
- Paleta canônica aprovada: `--bg:#0b1016`, `--panel:#121a24`, `--line:#1f2c3a`,
  `--ultra:#1fd1c4` (turquesa, acento único), `--conc:#ff3d8b` (magenta só-concorrente),
  `--text:#dce6f0`, `--muted:#7d97ad`.
- Tipografia: Google Fonts CDN (Space Grotesk + IBM Plex Sans + IBM Plex Mono);
  fallback gracioso para sans-serif do SO.
- CSS prefixado com `.ui-proto-` — sem conflito com CSS global do Streamlit.
- Acessibilidade: contraste AA, `prefers-reduced-motion`, `focus-visible`.
- Assinatura hexagonal: `clip-path: polygon(...)` nos KPI cards (único motivo decorativo).
- `kpi_card_html()` e `detail_panel_html()` — helpers de HTML.

**`src/motor_expansao/dashboard/ui_proto.py`** (novo):
- `render_proto_page()`: layout 3-painéis (`st.columns` [1,3,1]).
  - Esquerda: KPIs sumários + legenda de score.
  - Centro: mapa Leaflet client-side (via `render_mapa_leaflet`).
  - Direita: detalhe do top hex do recorte.
- `gerar_recorte_json(uf, ...)`: lê parquets enriquecidos (READ-ONLY),
  filtra pop ≥ 5.000 + score ≥ 20, limita a 500 hexes, salva em
  `data/cache/ui_proto/<UF>.json` (gitignored). Determinístico.
- `render_mapa_leaflet(data)`: `st.components.v1.html` com Leaflet 1.9.4
  + h3-js 4.1.0 por CDN; pan/zoom/clique sem round-trip.
- `is_proto_enabled()`: lê `ULTRA_PROTO=1` (env) ou `session_state["show_ui_proto"]`.

**`streamlit_app.py`** (modificado, opt-in apenas):
- 7 linhas adicionadas no início de `main()`:
  se `ULTRA_PROTO=1`, chama `render_proto_page()` e retorna imediatamente.
  Produção (pydeck/abas) **preservada byte-a-byte como default**.

### Fase B — Mapa Leaflet

HTML embutido no `st.components.v1.html`:
- CartoDB DarkMatter como basemap (coerente com tema escuro do PoC).
- `HEX_DATA` e `COLOR_MAP` embutidos como variáveis JS inline.
- `h3.cellToBoundary()` (h3-js) → `L.polygon()` (Leaflet) por hex.
- Clique: destaca hex, exibe painel de detalhe com score/pop/renda/oferta.
- Fallback gracioso: sem hexes → `map.setView(Brasil default, 4)`.

### Anti-default checklist (respondido)

1. **Paleta NÃO é verde-ácido nem cream+serif?** SIM. Dark carvão-azulado (#0b1016)
   + turquesa (#1fd1c4) + magenta (#ff3d8b). Sem verde-ácido nem cream.
2. **Tipografia deliberada?** SIM. Space Grotesk (cartográfico/técnico) + IBM Plex
   Sans (engenharia) + IBM Plex Mono (dados). Não é Inter/JetBrains default.
3. **UMA assinatura + resto contido?** SIM. clip-path hexágono só nos KPI cards.
4. **Sem decoração sem significado?** SIM. Barra lateral nos cards indica tipo de
   métrica; hexágono ancra identidade H3; mono comunica precisão dos dados.
