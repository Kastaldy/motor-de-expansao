## Riscos e mitigação

- **Match por nome impreciso** (EngCorpo: homônimos, grafias) → exigir `cod_municipio` no match quando disponível;
  match exato determinístico; não-casados auditados, nunca silenciosos.
- **Coords Skyfit corrompidas/ inversão LOG×LAT** → `parse_skyfit_coord` repara separador de milhar e valida
  faixa Brasil (lat∈[-34,5], lng∈[-74,-34]); fora da faixa ⇒ flag, sem derivar hex. Verificado: primárias OK
  reparadas e fallback caem 100% no Brasil.
- **Cobertura parcial de hex Skyfit** (≈135–143 OK + fallback) → aceitar como cobertura parcial + flags
  (`hex_resolvido`, origem da coord); nunca descartar unidade sem coord. Geocoding ao vivo fica fora (sem API).
- **Fontes gitignored ausentes no CI** → toda lógica testada por fixtures; `main()` só lê fontes reais em runtime local.
- **PII vazando** → relatório de auditoria só com agregados; logs sem nome/endereço.
- **Quebra de read-only** → nenhuma função escreve em paths do M1; teste/QA confere git status.
- **Dependência xlsx (openpyxl)** → confirmar no ambiente; se ausente, Builder adiciona a dep de leitura (não de dados).
